## 活动任务与优先顺序

用户于 2026-09-20 随后授权提交推送已验收的 M1 收尾批次，并继续下一步计划；先完成本批提交推送，再启动 M2 核心任务。下列为开发优先顺序，不代表已实现。详细入口与验收建议见[M1 收尾后的计划](_fin/260920/M1-02-图层检查与测试样本恢复.md#后续计划与边界)。

1. M2 核心选区与不可变任务快照：按[选区与任务](../docs/04-选区与任务.md)先实现选择版本、范围规范化、快照、任务绑定／幂等释放及有界内容查询，再接入界面；查看器单选不是任务授权。
2. M2 桌面交互与薄契约：复用核心规则接入图层多选、矩形草稿、坐标转换与吸附，验证修订、乱序及失败恢复。
3. M3 素材导出 → M4 MCP：固定快照的参考图和独立素材导出先行，随后由 MCP 复用相同服务，最后验证真实 H5 模块闭环。

解析兼容问题与更长 WebView 资源观察单独安排；不为进入 M2 提高默认预算、推导 CSS 或扩大复杂素材范围。此次提交推送授权限于已验收的 M1 收尾批次；后续新增 M2 修改先留在本机，提交推送须另获明确指示。
