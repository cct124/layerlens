# M3-01 固定快照局部参考图

## 目标与验收

让已固定任务或仍有效的快照能够获取原稿局部参考图，在改选、关闭标签、重载及源路径变化后继续使用原修订。核心、桌面和开发 MCP 复用同一服务；产品 MCP 在 M4 接入，不在本任务注册占位产品工具。

- 按[参考图规范](../../../docs/03-PSD数据与素材.md#参考图与独立素材)区分局部合成参考与独立素材。输出不包含遮罩、选框、控制点或 Agent 高亮。
- 请求显式绑定任务或快照；返回文档／修订／快照身份、`requestedBounds`、`actualBounds`、输出尺寸、实际比例、来源及能力限制。
- 裁剪与画布求交后向外取整；未知／无正面积参考范围、空交集、无合成图和资源不足均明确失败。
- 关闭或重载不取消已固定范围；任务释放拒绝新的读取，已接受请求保有独立租约。主动清理在计算与发布检查点拒绝失效数据。
- 格式、契约、核心像素／生命周期回归、桌面及开发 MCP 场景通过，Windows CI 对相同提交形成报告。

## 已定位基础与必须处理的差异

- `documents/selection/model.rs` 的 `SnapshotLease` 持有稳定 `DocumentLease`，已经提供修订、源指纹、`reference_bounds` 与 `ensure_valid`；`SelectionHandle` 负责解析任务／快照及生命周期错误。
- 当前 `documents/preview/` 只提供打开文档的保存时合成图；`worker.rs` 发布时要求修订仍在打开标签中，关闭／重载会取消其预览。任务参考图必须使用已接受的快照租约检查有效性，不能直接套用“标签仍打开”的发布判据。
- `psd/adapter.rs` 提供保存时像素解码与有界 PNG 编码基础；第三方对象仍通过适配器隔离，不让协议或前端访问内部解析树。
- 现有 `PreviewLease`、输出预算、LRU、完成移交与取消裁决优先复用；新增参考图缓存仍计入总体输出额度。`WorkspaceHost` 与 `workspace/access.rs` 继续统一桌面／测试协议的准入与发布复检。

## 实施顺序

### 第一批：范围与图像契约

1. 从上述入口及全部引用检索，形成核心请求／结果 Rust 类型及必要错误映射；对外 DTO 从 Rust 生成，Schema 使用同一来源。
2. 请求固定 `scope`，不提供隐式 `current` 或任意源路径。区域采用已固定矩形；图层采用参考边界并集并保留缺失／几何退化警告，不能重算成当前选区。
3. 把求交、像素向外取整、尺寸及比例计算写成无 I/O 的规则。首版默认 1×；若提供最大输出尺寸，只允许显式正整数上限下的等比缩小，禁止隐式放大。编码前确定实际整数尺寸并保留实际比例；采样算法与透明边缘规则在像素样本验证后固定。
4. `requestedBounds` 保留原请求范围，`actualBounds` 表示文档像素裁剪范围，缩小后的输出尺寸单独记录。不得把 CSS 缩放或设备 DPI 写回文档坐标。

### 第二批：核心后台、缓存与生命周期

1. 在副作用前解析并验证 scope、预留请求／解码／输出额度，接受时固定独立租约；复用有界后台，明确与打开／当前画布预览共享队列的顺序及取消归属。
2. 为当前画布预览和固定范围参考图区分请求目标与发布规则，共用解码、编码和额度管理；保持旧入口的关闭／重载取消行为。
3. 缓存身份包含文档修订、参考范围、实际尺寸及渲染参数；共享输出只计一次，最后引用释放才归还。缓存不得无限固定源修订，任务也不强制常驻解码像素。
4. 计算开始及发布前检查主动清理失效。关闭标签、任务释放、请求断连、取消和应用退出分别验证；锁内只裁决状态，解码和大对象析构在锁外。

### 第三批：桌面与开发 MCP 闭环

1. 在任务内容区域增加实际可用的参考图查看入口，展示所属范围、尺寸、来源和能力限制；状态由核心返回，不从当前画布截图。
2. 旧请求晚到不能替换新任务图像；更换目标／清理／卸载时释放 Blob 与请求资源，失败保留可重试原因。
3. 开发 MCP 接入同一应用服务，返回标准图像内容和结构化元数据；`data` 仍属于请求固定范围，`userSelection` 独立反映最新已提交选择。沿用图像与完整回复预算，不通过提高上限适配测试。
4. 将稳定场景纳入既有 Windows 回归与产物收集；保持普通发行构建无开发入口。
