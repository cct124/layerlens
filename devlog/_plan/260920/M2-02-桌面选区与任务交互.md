## 已完成

- 核心加入 `SelectionHandle`，共享同一注册表，不持有加载线程；保留 M2-01 服务入口并统一转发，退出后句柄拒绝新操作。
- `ServiceSnapshot` 在同一次短锁中投影文档和选区，通知不持有修订强引用、不携带全文；规范解析会话／ID／游标，任务按 ID 有界续读，终态保留固定文档与范围摘要。
- `selection_contract` 生成 TypeScript DTO；新增最小权限 `selection_request`，一个选区线程、一个排队名额。请求 64 KiB、完整回复 256 KiB，内容页另预留 1 KiB 外层；变更前保留 8 KiB 小型回执额度，拒绝预算不足的副作用。
- 桌面图层勾选提交范围、名称点击只检查；勾选等核心确认才更新。任务可固定、列举、查看内容、复制引用和释放，关闭全部标签后仍可使用；复制失败提供只读引用框。创建结果不确定时重试复用请求 ID，不用名称代替任务身份。
- 复用工作区权威选择和既有文字详情校验；新增请求关联、固定快照分页及会话／展示代次失效处理。切换范围清除旧范围内容，但不改变任务查看目标。
- 桌面仅将工作区已锁定的 `serde`／`serde_json` 用于运行时预算计数；`Cargo.lock` 只新增桌面对已有 serde 的依赖边，没有新增包或升级版本。
- 第二批增加 `region` 请求，复用核心区域校验、命中和快照提交；Rust 类型生成更新，保持原命令权限及资源预算。前端草稿仅保存文档坐标，不复制图层命中规则。
- `regionDraft.ts` 提供坐标正逆转换及有边界的矩形草稿；画布支持新建、框内移动、八个控制点调整、框外遮罩和重新框选。松开且拖动至少 3 CSS px 才提交有效变更；点击、零面积和未改变范围不提交。Esc、指针取消／捕获丢失、切换工具／标签、重载、关闭、失焦或视图变换取消草稿。
- 任务面板优先显示范围、图层计数和任务名称，技术标识／引用默认折叠；点击复制展开手动复制区。补充本次运行期限、尚未接入 AI、空区域、部分相交文字仍保留全文的提示，任务列表有界滚动。
- 第三批新增中键临时平移，选框和控制点上同样可用；处理左键草稿中追加中键、中键先松开、失焦及捕获丢失。点击移动工具复用核心 `clear`，由 `useCanvasTool.ts` 等待对应回执与空摘要后切换；失败、忙碌和迟到响应不会伪造清空，其他文档与固定任务保持原范围。
