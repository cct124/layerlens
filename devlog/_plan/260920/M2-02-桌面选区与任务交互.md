# M2-02 桌面选区与任务交互

## 目标与验收

基于 [M2-01 核心选区与任务快照](../../_fin/260920/M2-01-核心选区与任务快照.md)，让桌面能够明确提交、查看和固定设计范围。遵循[产品与交互](../../../docs/01-产品与交互.md)、[选区与任务](../../../docs/04-选区与任务.md)及[M2 验收](../../../docs/06-实施与验收.md)，不在前端复制权威选区或任务规则。

- 图层多选和矩形选择均经核心确认；查看器检查焦点与任务授权明确区分。提交失败保留此前有效选区和界面反馈。
- 新建、移动、调整边角及吸附只更新草稿；有效松开才提交一次，同范围不递增版本。Esc、中键平移、切换标签、关闭和重载取消草稿；点击移动工具则取消草稿并经核心清空当前范围，晚到结果不覆盖新状态。
- 文档像素与画布坐标转换、缩放／平移／DPI 下定位正确；吸附采用屏幕距离，稳定处理同距目标，支持开关与 Alt 临时关闭，隐藏图层不参与。
- 当前范围及区域内容使用同一个已提交快照；分页保留固定游标，切换标签恢复其选择，旧会话／旧修订／乱序响应可识别且不会被应用。
- 可以创建、列举、查看和释放固定任务，复制包含 `sessionId`／`taskId` 的引用；名称不作为唯一标识，已关闭／重载文档的任务仍显示自身固定修订。
- DTO 从 Rust 生成，外部参数运行时校验；范围计算、内容组装和释放走有界后台，资源不足或回执无法容纳时不产生未确认副作用。

## 已完成

- 核心加入 `SelectionHandle`，共享同一注册表，不持有加载线程；保留 M2-01 服务入口并统一转发，退出后句柄拒绝新操作。
- `ServiceSnapshot` 在同一次短锁中投影文档和选区，通知不持有修订强引用、不携带全文；规范解析会话／ID／游标，任务按 ID 有界续读，终态保留固定文档与范围摘要。
- `selection_contract` 生成 TypeScript DTO；新增最小权限 `selection_request`，一个选区线程、一个排队名额。请求 64 KiB、完整回复 256 KiB，内容页另预留 1 KiB 外层；变更前保留 8 KiB 小型回执额度，拒绝预算不足的副作用。
- 桌面图层勾选提交范围、名称点击只检查；勾选等核心确认才更新。任务可固定、列举、查看内容、复制引用和释放，关闭全部标签后仍可使用；复制失败提供只读引用框。创建结果不确定时重试复用请求 ID，不用名称代替任务身份。
- 复用工作区权威选择和既有文字详情校验；新增请求关联、固定快照分页及会话／展示代次失效处理。切换范围清除旧范围内容，但不改变任务查看目标。
- 桌面仅将工作区已锁定的 `serde`／`serde_json` 用于运行时预算计数；`Cargo.lock` 只新增桌面对已有 serde 的依赖边，没有新增包或升级版本。
- 第二批增加 `region` 请求，复用核心区域校验、命中和快照提交；Rust 类型生成更新，保持原命令权限及资源预算。前端草稿仅保存文档坐标，不复制图层命中规则。
- `regionDraft.ts` 提供坐标正逆转换及有边界的矩形草稿；画布支持新建、框内移动、八个控制点调整、框外遮罩和重新框选。松开且拖动至少 3 CSS px 才提交有效变更；点击、零面积和未改变范围不提交。Esc、指针取消／捕获丢失、切换工具／标签、重载、关闭、失焦或视图变换取消草稿。
- 任务面板优先显示范围、图层计数和任务名称，技术标识／引用默认折叠；点击复制展开手动复制区。补充本次运行期限、尚未接入 AI、空区域、部分相交文字仍保留全文的提示，任务列表有界滚动。
- 第三批新增中键临时平移，选框和控制点上同样可用；处理左键草稿中追加中键、中键先松开、失焦及捕获丢失。点击移动工具复用核心 `clear`，由 `useCanvasTool.ts` 等待对应回执与空摘要后切换；失败、忙碌和迟到响应不会伪造清空，其他文档与固定任务保持原范围。
- Esc 补充：区域工具下、画布获得焦点且没有拖动时，按 Esc 通过核心清空范围并保留工具；拖动或中键平移时只取消手势，忽略长按重复及输入法组合事件。范围已空不发请求，忙碌时不追加操作，画布外任务名称输入不受影响。
- 第四批使用中性深灰主题和本地 SVG 工具／图层类型图标，去掉高品牌栏及装饰背景；文档标签仅占画布列，底部保留缩放和原稿尺寸。右上属性／文档、右下图层／任务独立滚动，视图切换保留搜索、任务草稿和滚动；错误提示不藏在任务标签里。
- 顶部文件／视图／窗口菜单收纳已有操作，工具选项在下方；支持禁用项、悬停切换、方向键、Alt 访问键及菜单 Esc 隔离。菜单命令复用既有核心／视图入口，不新增依赖、应用业务 IPC 或编辑能力。V／M 工具快捷键与原按钮语义一致。
- 后续按用户授权将菜单与自定义标题栏合并，关闭系统装饰，提供拖动、双击最大化／还原及三种窗口按钮；为 `main` 增加 5 项最小窗口权限，正常关闭仍走既有退出清理。窗口状态查询合并、订阅释放和浏览器预览隔离均有回归，详见标题栏补充记录。
- 后续通过 Reka UI Splitter 提供右侧宽度与上下比例调整、边界约束、本机尺寸记忆、双击／菜单重置及键盘操作；按用户补充取消可见分隔条和悬停／拖动高亮，只保留透明热区与调整光标。取消手势不清空范围，恢复布局不销毁业务组件，详见可调整面板补充记录。
