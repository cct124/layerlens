# M2-02 桌面选区与任务交互

## 目标与验收

基于 [M2-01 核心选区与任务快照](../../_fin/260920/M2-01-核心选区与任务快照.md)，让桌面能够明确提交、查看和固定设计范围。遵循[产品与交互](../../../docs/01-产品与交互.md)、[选区与任务](../../../docs/04-选区与任务.md)及[M2 验收](../../../docs/06-实施与验收.md)，不在前端复制权威选区或任务规则。

- 图层多选和矩形选择均经核心确认；查看器检查焦点与任务授权明确区分。提交失败保留此前有效选区和界面反馈。
- 新建、移动、调整边角及吸附只更新草稿；有效松开才提交一次，同范围不递增版本。Esc、切换工具／标签、关闭和重载取消草稿，晚到结果不覆盖新状态。
- 文档像素与画布坐标转换、缩放／平移／DPI 下定位正确；吸附采用屏幕距离，稳定处理同距目标，支持开关与 Alt 临时关闭，隐藏图层不参与。
- 当前范围及区域内容使用同一个已提交快照；分页保留固定游标，切换标签恢复其选择，旧会话／旧修订／乱序响应可识别且不会被应用。
- 可以创建、列举、查看和释放固定任务，复制包含 `sessionId`／`taskId` 的引用；名称不作为唯一标识，已关闭／重载文档的任务仍显示自身固定修订。
- DTO 从 Rust 生成，外部参数运行时校验；范围计算、内容组装和释放走有界后台，资源不足或回执无法容纳时不产生未确认副作用。

## 验证计划

- 核心／契约：有界任务列表、线协议 ID 与游标校验、错误映射、资源预算和生成类型一致性。
- 桌面适配：唯一核心、原子选择采样、有界后台、旧修订及乱序请求、任务幂等、退出清理、最小权限。
- 前端：坐标往返、多选和草稿状态机、吸附同距／缩放／边缘／禁用、异步取消和旧响应丢弃；不以组件测试替代桌面验收。
- 集成：完整 `npm run check` 后，使用已存在的规模／文字样本手测打开两份文档、选择／切换／重载／关闭、任务固定／释放及分页；如需性能结论，单独记录构建模式、样本、耗时和资源基线。

## 下一步与阻塞

3. **最后接区域草稿**：复用 `PreviewCanvas.vue` 和 `canvasView.ts`，独立拆出草稿状态机、坐标与吸附纯逻辑；查询结果携带文档修订与草稿序号，松开才执行核心准备／提交。
