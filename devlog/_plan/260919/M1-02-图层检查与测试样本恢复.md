# M1-02 图层检查与测试样本恢复

## 目标与验收

恢复可复现的本机公开 PSD 样本集，继续完成 M1 图层树、只读属性和画布定位。复用核心文档修订、资源预算与桌面通知；保持 PSD 只读，不扩展复杂素材、区域选择或 MCP 业务。

- 图层树可展开、搜索、单选；选择由核心管理，视图状态按文档恢复；重载成功清空选择，失败保留。
- 属性保留原文、分段样式、单位、来源和能力限制；画布定位使用明确的几何边界，不宣称精确像素命中。
- 验证重载、关闭、切换、晚到响应、无合成预览、隐藏组、文字边界及规模场景；补验 M1-01 原生桌面操作。

## 已完成与验证

### 样本恢复与能力盘点

- 新增 `scripts/fetch-psd-samples.ps1` 与目录清单 `scripts/psd-samples.json`：固定 psd-tools 提交 `51082d37f041425a9721e8a4252214a12b35cfa9`，逐文件校验长度与 SHA-256／Git blob，只写 `.local/`，不覆盖已有文件。
- 本机默认 Node/npm 为 24.21.0/11.19.0，不符合仓库锁定；`npm ci` 按 engine 检查拒绝。改用 `.local/toolchain/` 下经官方 SHA-256 校验的 Node 24.19.0（附 npm 11.17.0），不改变全局版本。
- `.local/public-psd-260919/` 共 53 份 PSD/PSB：psd-tools 测试集覆盖基础图层、层级与隐藏、空组、文字与 Unicode、形状与填充、智能对象、蒙版与效果、颜色模式与位深及 PSB 拒绝；GraphicBurger 提供 4 份真实页面模板。许可原文留在 `source-info/`，资源不再分发。
- 能力盘点结果写入 `.local/public-psd-260919/results/corpus.json`：默认额度 53 次运行 36 成功；对 3 份超预算样本用实验额度（256 MiB／200 Mi 像素／256 MiB 解码）重跑，`diff.psd`、`12_contacts.psd` 通过。
- 失败分类：12 份不符合首版 RGB/8 位、3／4 通道子集（含 16／32 位位深与 CMYK、Grayscale、Lab、Index、Bitmap 颜色模式），1 份 PSB，3 份默认额度超限（含 `01_home_light.psd`），另有 1 份候选兼容问题；合计 17 次失败。
- 候选兼容问题：`1layer.psd` 报 `InvalidInput`／“PSD 图层信息区包含未声明的数据”，与历史私有稿无关，已留复现入口，本任务不顺手改预检。`01_home_light.psd` 即使提额仍在解析 RAW 图案通道时报 `Invalid color pattern`，与历史记录的失败原因一致。

### 核心实现

- `documents::inspection` 提供有界图层列表与单图层详情：列表按 `offset`／`limit`（≤128）分页、响应 ≤256 KiB；文字按 UTF-16 分页（≤2048 code unit、≤128 段样式、单项 ≤32 KiB、诊断 ≤32 条），不拆分代理对；字体与 `unverifiedEngine` 单位限制保持不变。
- `DocumentService::select_layer` 用 `Arc::ptr_eq` 校验修订，重载／关闭／旧修订拒绝；快照新增 `selected_layer_id`，工作区通知仍不含完整图层或文字。
- 新增领域错误 `StaleRevision`、`InvalidQuery`、`LayerNotFound`，并补核心单测与集成测试。

### 桌面适配与界面

- 契约新增 `SelectLayer`、`LayerQuery`／`LayerResult`／`LayerResponse`；`read_layers` 命令以 `SingleOperation` 加 `spawn_blocking` 组装详情，capability 只授权 `main`。
- 前端新增图层树（虚拟窗口、搜索保留祖先、展开／折叠）、只读属性面板（复制、文字分页、诊断）、按文档保存的树视图状态与画布边界定位；晚到响应按 generation 丢弃，分页按 128/页续读。
