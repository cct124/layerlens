### 核心实现

- `documents::inspection` 提供有界图层列表与单图层详情：列表按 `offset`／`limit`（≤128）分页、响应 ≤256 KiB；文字按 UTF-16 分页（≤2048 code unit、每类 ≤128 段样式、单项 ≤32 KiB、诊断 ≤32 条），不拆分代理对；本次修复使文字页同时按完整详情 JSON ≤256 KiB 缩短，单项属性和不可分页元数据超限仍明确失败。字体与 `unverifiedEngine` 单位限制保持不变。
- `DocumentService::select_layer` 用 `Arc::ptr_eq` 校验修订，重载／关闭／旧修订拒绝；快照新增 `selected_layer_id`，工作区通知仍不含完整图层或文字。
- 新增领域错误 `StaleRevision`、`InvalidQuery`、`LayerNotFound`，并补核心单测与集成测试。
