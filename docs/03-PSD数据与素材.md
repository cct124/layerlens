# PSD 数据与素材

## 数据原则

对外使用 LayerLens 规范化模型，保留 PSD 来源和能力限制。原始值、推导值及不可用值必须可区分；数值 `0`、空字符串与“未读取到”不能混用。

规范化用于整理原稿事实及解释其语义，不直接暴露解析库内部对象，也不生成目标项目的 CSS。工具可提供有明确依据、保留来源的设计空间推导值；项目 CSS、布局、响应式策略及字体替代遵循[产品职责边界](01-产品与交互.md#目标与场景)，由 Agent 决定。尚未确认的单位明确标记，不用假定单位补齐；这类局部不确定性不阻止其他已验证数据与预览按能力状态提供。

本文定义语义和必要字段。工程实现时再形成可执行的 Rust 类型与 Schema，并保持界面、MCP 和导出清单一致。

## 文档与图层

| 对象               | 必要信息                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------- |
| `Document`         | `documentId`、`documentRevision`、名称、宽高、分辨率、颜色模式、位深、色彩配置、能力报告  |
| `Layer`            | `layerId`、父 ID、子 ID、原始名称、类型、堆叠顺序、可见性、不透明度、边界、可用样式和警告 |
| `TextData`         | 原文、分段字符样式、段落样式、文字变换、字体引用及缺失信息                                |
| `CapabilityReport` | 文档、预览、文字、图层位图和效果导出的支持状态及原因                                      |
| `AssetManifest`    | `exportId`、`exportRoot`、文档修订、范围、导出参数、逐项终态、文件与依赖信息              |

- `documentId` 标识本次打开的逻辑文档；已打开文件按规范化路径去重，重复打开时沿用 ID 并激活原标签。重新加载保持 ID 并递增 `documentRevision`；关闭后重新打开或应用重启后使用新 ID，不以相同路径替换旧任务引用。
- `layerId` 在文档修订内唯一。PSD 内部 ID 可作为来源信息，但不能假设其存在且唯一；名称和路径仅用于展示与查询。
- 所有图层引用同时受文档与修订约束，不跨修订猜测对应关系。跨修订映射作为后续能力。
- 层级、堆叠顺序与父组关系必须保留；记录自身可见性和继承后的有效可见性。
- 图层类型至少区分组、文字、位图、形状、智能对象、调整图层和未知类型。未知类型保留基础元数据及警告，不冒充普通位图。

区域内容以规范化图层为基础，为命中目标附加 `intersection`（`contained` 或 `partial`）和 `intersectionBounds`，使用与快照命中规则一致的边界依据；结构组仅在具有可用边界且交集信息适用时提供这些字段。保留图层完整边界、层级、顺序、有效可见性、关键样式和能力状态；这些交集信息属于选区投影，不写回原始图层模型。

## 坐标与单位

- 文档坐标原点为画布左上角，X 向右，Y 向下；对外边界采用 `{ x, y, width, height }`，单位为文档像素。
- 保留负坐标、越出画布的图层和小数精度。画布缩放、设备像素比、CSS 适配比例不写回文档坐标。
- 图层 `bounds` 表示几何边界，保留合法的零面积边界；无法取得时为 `null` 并附原因，不能伪造尺寸。已知边界的坐标必须有限，宽高为有限非负数。组边界可由已知子图层边界并集推导，标记 `derived` 及依据；仅部分子图层边界已知时明确不完整。
- `visualBounds` 表示包含已确定效果的完整视觉范围，无法可靠确定时为 `null` 并说明原因，不以不完整的组边界冒充完整视觉范围。没有可用正面积边界的图层保留元数据，但不参与区域命中或边缘吸附。
- 矩阵约定为 `[a, b, c, d, tx, ty]`，映射关系为 `x' = a*x + c*y + tx`、`y' = b*x + d*y + ty`。注明其源空间与目标空间，禁止对已经转换到文档空间的边界重复应用矩阵。
- 用户选区和输出裁剪矩形的坐标必须有限，宽高必须为有限正数。预览裁剪先与画布求交，再向外取整到像素边界，返回实际裁剪范围；空交集报错。该正面积要求不用于拒绝合法的零面积原始图层边界。

CSS 尺度由目标 H5 项目决定。Agent 只有明确设计宽度和目标 CSS 宽度后，才可按 `CSS 值 = 文档像素值 × 目标 CSS 宽度 / 设计宽度` 换算。例如 750 文档像素映射到 375 CSS 像素时，32 文档像素对应 16 CSS 像素；不能将这个比例作为所有项目的默认值。这是 Agent 使用设计数据的说明，不是工具生成 CSS 的要求。

## 文字与样式

保留完整文字，不裁剪换行或首尾空白。字符样式至少覆盖字体名称、字号及单位、颜色、可用字重、字距和行距；段落样式保留对齐等可读取属性。

- 同一文字图层中的不同字号、颜色和字体通过 `styleRuns` 表达；段落属性通过 `paragraphRuns` 表达。
- 字符区间统一使用原始文本的 UTF-16 code unit 索引，左闭右开 `[start, end)`。Rust 边界层负责转换，不能直接当作 UTF-8 字节偏移。
- 保留文本引擎中的原始单位和变换。若原始字号为 pt，只有分辨率已知且解析器尚未转换时，才按 `pt × DPI / 72` 推导像素值。
- 文字缩放与设计稿到 CSS 的缩放分别处理。旋转、倾斜、非均匀缩放无法用单个字号完整表达时，保留矩阵并标记限制。
- 保留字体原始名称和可用标识，不仅靠字体名称中的字符串推测字重。字体文件是否在本机或目标项目可用另行判断。
- 已栅格化文字按图像处理；首版不通过 OCR 推测原始字体和字号。

M0-01 当前实验输出（尚未接入桌面或 MCP）：

- 从原始 EngineData 读取属性，不使用候选库裁剪、去重或补默认字体后的样式。`indexMapping` 仅允许与 TySh 原文完全相同，或原文后额外一个 CR；只裁去该引擎结束符对应的区间，保留 TySh 自身的尾随 CR。其他差异返回 `textMismatch`，两类区间均为 `null`。
- 字符和段落区间分别校验数组数量、正整数长度、累计完整覆盖及 UTF-16 代理对边界。每类最多 16384 段，超限或非法时只关闭该类别；`null` 表示不可用，空数组表示已验证的空文本。语法损坏、非法 UTF-16、非有限数值等解析错误仍使读取失败。
- 已读取的属性使用 `{ value, source }` 表达，`source` 是完整 EngineData 路径。仅允许同类 `DefaultRunData` 的显式属性继承；无效局部值不回退，存在未展开的局部样式表引用时不继承默认数据。其余属性缺失／非法／未支持通过 `null` 与诊断表示，不推测外部样式表。
- 字号、行距、字距、基线偏移、缩进和段间距保留 `{ value, unit: "unverifiedEngine" }`；横纵缩放、自动行距保留引擎数值，不计算最终排版。当前没有独立参考确认这些量的物理单位，72／300／缺失 DPI 样本仅证明读取没有重复缩放。原始矩阵独立保留，不提供 CSS 派生值。
- 字体必须来自显式整数索引对应的 `ResourceDict.FontSet`，只返回源中名称、可用 family/style 字段及索引；`FauxBold`／`FauxItalic` 不推导 CSS 字重。颜色仅接纳 `Type=1` 的 0–1 ARGB 通道，其他模型明确未支持；不声明为 sRGB。`styles` 保持 `partial`，完整视觉、字体可用性和单位仍待独立参考。

区域部分经过文字图层时，返回该图层原文及分段样式，并标记部分相交；不能仅凭矩形边界推断哪些字符被选中。区域选择与显式 `textRange` 选择分别处理。

长文本超出响应预算时使用 `textSlice: { start, end, totalLength, nextStart }` 标记当前片段，各字段均基于原文 UTF-16 单位；未读完时以 `nextStart` 续读，读完为 `null`。片段不得拆分代理对，相关 `styleRuns` 和 `paragraphRuns` 随片段返回并保留原文索引，续读后可重建原文与样式。未续读内容、源数据缺失和解析不支持分别标记，不能以空字符串代替。当前每页与响应预算见[技术架构](02-技术架构.md#当前核心文档与预览实现m1)。

单个样式值的表达示意：

```json
{
  "status": "available",
  "value": 32,
  "unit": "pt",
  "source": "psd"
}
```

`status` 为 `available`、`missing` 或 `unsupported`；后两者的 `value` 为 `null` 并附原因。`source` 区分 `psd` 和 `derived`，推导结果必须注明依据。实际接口可按样式对象归并公共信息，但不得丢失这些语义。

RGB 颜色同时保留来源色彩空间，规范化输出使用 R/G/B 为 0–255、A 为 0–1 的 RGBA。未知色彩配置不能静默当作已完成 sRGB 转换；浏览器与原稿色彩一致性单独验证。

## 能力与兼容性

颜色模式与位深的支持范围由解析器能力和样本验证确定。RGB／8 位 PSD 作为基础验证样本，不作为产品输入的固定限制。解析器“能读取效果描述”和“能正确渲染效果”分别报告。

| 能力状态      | 含义                                       |
| ------------- | ------------------------------------------ |
| `supported`   | 当前实现支持该对象所需的已声明能力         |
| `partial`     | 只能取得部分数据或只能近似处理，附具体限制 |
| `unsupported` | 当前实现无法提供该能力                     |

能力状态用于表达实现边界，不等同于与 Photoshop 逐像素一致。PSD 文档、文字读取、保存时合成图、单图层位图和独立素材导出分别判定。

M0-01 核心／CLI 实验中的图层 `exportBlockers` 保留全部已知拒绝因素：未支持类型、不可见、全局蒙版、祖先视觉依赖、自身视觉依赖、缺少 RGB 通道及无可用位图。`emptyBitmap` 表示零面积或缺少原始像素数据，也可能出现在组等非位图节点上。同一节点可有多项限制，汇总计数不能相加作为节点总数；另列位图子集，避免把类型限制误判为唯一阻塞。主要提示仍由 `export.reason` 提供，解除单项限制不表示已经具备独立导出能力。

复杂蒙版、剪贴关系、父组效果、混合模式、渐变、智能对象及字体兼容性通过样本确定。遇到当前无法处理的格式或特性时明确拒绝或只开放已验证的只读能力，不返回看似完整的默认样式。

## 参考图与独立素材

| 输出       | 来源                           | 用途与限制                                     |
| ---------- | ------------------------------ | ---------------------------------------------- |
| 整页参考图 | PSD 保存的合成图               | 原稿视觉参考；不保证反映文件中的隐藏内容       |
| 局部参考图 | 整页参考图按范围裁剪           | 包含该区域原稿中的背景和叠加内容，用于对照实现 |
| 独立素材   | 选定图层或组的像素与受支持效果 | 用于 H5 图片资源，需处理透明度、蒙版及合成依赖 |

参考图、预览缓存和独立素材均从原稿数据生成，不包含区域框外遮罩、选框、控制点或 Agent 高亮等界面辅助元素。

缺少可用合成图时，首版返回 `PREVIEW_UNAVAILABLE`，不自动重绘一张可能失真的整页图。

局部预览返回 `requestedBounds`、`actualBounds`、输出像素尺寸、比例和来源说明。区域选区使用其矩形；图层选区使用快照固定的参考边界并集，优先取可靠 `visualBounds`，否则使用可用 `bounds` 并标记可能截断的效果。无法取得全部目标边界时注明参考范围不完整，没有可用正面积边界时明确报错。

素材导出首版以 PNG、1× 为基线。其他倍率须作为显式选项并经过验证；放大已栅格化素材不代表增加真实细节。

## 素材清单与导出规则

| 信息 | 内容                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------ |
| 作业 | `exportId`、接受作业时固定的受控绝对根目录 `exportRoot`、导出参数及终态                                |
| 清单 | `publicationStatus`（`published`／`failed`）、清单文件相对路径 `relativePath`；发布失败时路径为 `null` |
| 范围 | `documentId`、`documentRevision`、`snapshotId`、可选 `taskId`                                          |
| 定位 | `assetId`、来源图层 ID、合成依赖图层 ID、`sourceBounds`、`actualBounds`、`selectionOrigin`、`offset`   |
| 文件 | 导出根目录下的 `relativePath`、格式、像素尺寸、校验值                                                  |
| 渲染 | 比例、透明度信息、色彩处理说明、能力状态及警告                                                         |
| 结果 | 全部规范化输出项的成功、失败或取消信息，整体是否部分完成；失败项不引用未发布文件                       |

PNG、1× 导出的 `sourceBounds` 是当前导出能够确定的完整视觉来源边界；`actualBounds` 将其左、上边界向下取整，右、下边界向上取整，表示实际 PNG 在文档中的覆盖范围。输出像素宽高等于 `actualBounds` 的宽高，不与画布或选区求交，也不自动裁去透明边距；阴影、负坐标和取整产生的透明填充均保留。无法确定完整视觉来源时按不支持处理；调用方明确允许近似时，记录实际采用的边界依据及可能缺失的效果，不宣称其覆盖完整原稿效果。

`selectionOrigin` 在快照内固定：区域选择使用区域左上角；图层选择使用与局部预览相同的参考边界并集左上角，在与画布求交或像素取整之前确定，沿用其边界依据和限制。没有可用正面积参考边界时明确报错。`offset` 为 `actualBounds` 左上角减去 `selectionOrigin`，因此素材超出选区时可为负数；它不使用 PNG 内首个非透明像素的位置，也不随分页、重试或当前选区变化。

- 图层名只参与经过清理的可读文件名，唯一性由 ID 保证。输出写入独立导出目录，不覆盖已有文件。
- 默认要求所需效果受支持；不支持时逐项报错。只有调用方明确允许近似导出时才提供近似结果，并附限制。
- 区域选区中的素材保留自身完整边界，可能超出选区矩形；仅参考图默认裁剪。不得悄悄裁掉阴影或越界装饰。
- 蒙版和剪贴等合成依赖与实现目标分开列出。依赖无法获取或超出已授权范围时明确失败，不能自动扩大任务目标；组请求也不能借助父子结构引用扩大授权，范围规则见[选区与任务](04-选区与任务.md)。
- 中间文件写完并校验后发布，清单只引用已完成文件。取消被接受后不再发布新成功项，此前发布的文件保留，未完成的规范化输出项记录取消原因。终态清单尝试独立落盘；发布失败时设置 `publicationStatus: failed`、清单 `relativePath: null`，仍可按保留的私有结果记录分页读取，已发布素材的路径不受影响。清单失败不计入素材失败项，但会影响作业终态及 `partial` 布尔值；状态规则见[技术架构](02-技术架构.md)，查询和清单发布失败的响应规则见[MCP 与 Agent 协作](05-MCP与Agent协作.md)。
- 文件位置由固定的 `exportRoot` 与 `relativePath` 连接并校验，所有结果均位于该作业的根目录内；Agent 不能传入任意根目录。桌面更改导出设置不改变已有作业或清单中的根目录；文件访问边界见[技术架构](02-技术架构.md)。
