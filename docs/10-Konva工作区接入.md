# Konva 正式工作区接入

## 状态与目标

Konva 已于 2026-10-17 选定，依据与历史限制见[渲染决策](09-渲染器对比实验.md#当前选型决定2026-10-17)。本方案于 2026-10-19 建立，正式合成画布和直接检查已接入代码，并通过本机开发 MCP 的显示及选择同步回归。两个完整资源循环实例仍超过增长斜率门槛，正式接入未完成全部验收；证据统一维护于 [RENDER-04](../devlog/_plan/261019/RENDER-04-Konva正式工作区接入.md)。完整图层重绘尚未进入正式路径。

首个产品出口是正式工作区中的缩放／平移和直接检查图层，保持既有选区、固定任务、清理及 PSD 只读约定。高清文字／形状属于后续出口；合成位图改由 Canvas 显示不会增加源像素细节。

## 模块与服务边界

数据流为 PSD → Rust 解析适配器 → 固定修订规范化数据／有界资源服务 → Konva 适配器 → 正式工作区。Rust 保持文档、检查图层、任务范围及快照的唯一权威；前端仅保存视图、悬停、候选和手势草稿。

| 模块         | 职责与约束                                                                                      |
| ------------ | ----------------------------------------------------------------------------------------------- |
| Rust 核心    | 规范化几何、能力诊断、修订租约、解码／输出额度、取消与失效；不依赖 Tauri 或 Konva               |
| 桌面适配     | 生产可用的受限读取、二进制资源传输与发布复检；桌面和测试 MCP 复用应用服务                       |
| 前端绘制模块 | `compositeRenderer.ts` 持有合成图和 Stage；复用现有坐标换算，正式模块不依赖实验页面／配置       |
| 工作区组件   | 组合绘制与输入、保留可访问 DOM 控件、投影核心结果；不复制解析或授权规则                         |
| 实验与测试   | 正式工作区由 MCP 直接验证；逐图层实验仍用独立适配器，诊断投影、大稿配置和测试字体隔离于普通发行 |

保持 Konva 10.9.0 与直接 TypeScript 适配器，当前不引入 `vue-konva`。已有 `render-lab = dev-mcp + core/render-lab` 特性不能直接转为生产依赖；按迁移需要拆出核心模块与正式 IPC。DTO 从 Rust 生成，资源绑定文档／修订，不接收任意路径。

首批复用现有合成预览及图层摘要，不因替换显示容器全量解码图层。后续场景元数据与 PNG 二进制分离、按需有界加载，第三方解析类型不穿透核心。默认单源 64 MiB 及已有解码／存活预算保持不变；实验大稿提额不能直接变成产品配置，正式大文件另行设计。

首批不增加生产 IPC：沿用 `read_preview`、`read_layers` 与核心 `selectLayer`。Konva 10.9.0 由开发依赖移到应用依赖，锁文件版本不变；仍为 MIT、浏览器 Canvas2D 路径，无新增字体或 WASM。普通构建明确允许 Konva，继续检查实验 HTML／命令／字体没有混入。

## 显示模式与保真边界

1. **合成预览**：Konva 绘制保存时合成图，检查边界和区域交互共享文档坐标变换。保留来源和色彩限制，作为首批正式显示与复杂文档回退。
2. **受支持图层重绘**：按验证后的契约绘制文字、形状与位图，逐层记录 `native`、`rasterFallback`、`unsupported`、`parserGap`。只有组合范围完整且视觉验收通过时才作为对应范围正式显示。
3. **诊断投影**：现有 `largeLayers` 等仍限于验证窗口；组、画板、效果、蒙版、剪贴、调整或 ICC 缺失时不能称为完整原稿。

不在完整合成图上叠加同一文字／形状，避免重复绘制与错误层级；无法建立正确组合边界时整体回退。加载失败、预算不足与没有合成图分别提示，不以空画布或部分节点冒充成功。正式缩放采样策略单独验收，实验 nearest 不自动成为产品默认。

字体须与源 PostScript 名、实际文件和字符覆盖建立可解释绑定；固定测试字体与本机私有清单不能直接进入发行。缺字体明确回退或标记，不静默替换。EngineData 未验证单位、分段／UTF-16、变换、基线、行距和换行逐项验证；高清首批从简单形状和有独立参考的文字开始，不扩大为任意中文排版保真。

## 检查选择与工具优先级

检查选择复用核心 `select_layer`，仅改变检查焦点、图层树和属性，不创建快照或改变授权。任务范围继续由勾选和区域提交建立，固定任务不受检查变化影响。

| 输入                | 正式接入约定                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| V／显式移动工具     | 保持明确清空当前任务范围、核心确认后进入平移模式的现有语义                                         |
| 平移模式左键点击    | “自动选择”开启时检查最上方有效候选；关闭时保持检查。开关初始关闭，本会话跨文档共用                 |
| 平移模式左键拖动    | 达到现有 3 CSS px 阈值后只平移，松开不提交检查选择                                                 |
| Ctrl + 左键点击     | 无其他手势时临时检查，不修改开关，不触发 V 切换／清空；松开 Ctrl 或失焦恢复                        |
| 区域模式左键        | 继续新建／移动／调整；无进行中手势时 Ctrl 点击可临时检查，超过点击阈值取消临时检查，不隐式提交区域 |
| 中键                | 优先临时平移，保留已提交范围、取消未提交草稿                                                       |
| Esc／失焦／捕获丢失 | 保持现有取消与清空规则，并撤销进行中的检查候选、Ctrl 和悬停                                        |

命中从完整、同修订的有界数据建立候选，搜索、树折叠和分页晚到不改变当前手势。有效可见性包含祖先；重叠按 PSD 堆叠顺序，首批检查叶图层，组仍由树检查，不提供占位的自动选择组模式。支持候选切换，点击空白清空检查。文字可使用来源边界，可靠路径／alpha 提高精度；缺少数据保留实际 `bounds` 等精度，不冒充像素命中。透明区和复杂效果边界分别验收。

松开时固定文档、修订和候选 ID，核心确认后显示边界；关闭、重载或切标签使旧回执失效。hover 不变更核心，拖动和缩放不每帧读取业务快照。

首批通过“切换重叠图层”按钮循环本次点击候选；新手势、变换、失焦或修订变化撤销候选。画布检查确认后展开树祖先、清除遮挡目标的搜索并定位该行，同时显示属性；搜索和折叠不参与命中计算。未完成分页或解码／绘制时不接管检查点击。

## 视图、取消与资源

区分文档像素、CSS 像素和物理像素，沿用每文档视图与坐标转换。Canvas 后备像素随容器和当前 DPR 更新，保留文档锚点并取消旧手势；面板调整、最大化／还原和跨屏重新布局，不沿用创建时固定 DPR。区域、检查框与图像共享变换。

每个绘制会话拥有 Stage、图片／Blob URL、字体引用、监听和代次。关闭／重载／清理／卸载使旧代次失效；晚到解码和字体资源也须释放。非活动文档仅保留有界视图及核心引用，不无限保留 Stage；缓存继续计费。画布资源与任务租约独立，释放 Stage 不释放固定任务。

绘制就绪、截图完成与物理呈现分别定义。同步 Canvas 读回用于诊断，不进入生产每帧路径；已有读回门槛保持原口径，产品交互指标另列，不能通过移除屏障改判历史 50.5 ms 失败。

首批只分配视口大小的表面，DPR 范围为 (0, 8]，单边最多 8192 物理像素，单表面最多 16,777,216 像素；超限明确提示，不能静默降 DPR 或分配文档大小的 Canvas。使用平滑采样；源合成图细节不会增加。`usePreview` 唯一持有 Blob URL，适配器持有 Image／Stage／RAF，换源、失败和销毁都解除图片引用、销毁节点及撤销回调。每次视图／尺寸变化使绘制代次失效，实际 draw 后下一帧才确认当前代次；无活动文档不保留 Stage。

## 分批实施与验收

| 批次             | 工作范围                                               | 出口                                                                       |
| ---------------- | ------------------------------------------------------ | -------------------------------------------------------------------------- |
| 准备批（已完成） | CI 依赖、设计／日志、逐轮显示观测                      | 干净环境可准备；MCP 识别真实焦点／尺寸变化，保存循环与终态；检查和构建通过 |
| 正式画布批       | 绘制边界、合成预览接入、直接检查、尺寸／DPR 和生命周期 | 主工作区与树／属性同步；旧区域／任务／清理回归通过，发行无开发入口         |
| 受支持重绘批     | 真实字体／简单文字、形状、位图和降级                   | 独立参考原尺寸及 200%／400% 验证，固定环境交互和资源门槛通过               |
| 后续扩展         | 按代表样本扩展复杂组合成、正式大文件策略               | 每项能力独立证据，不以诊断投影覆盖缺失项                                   |

功能测试使用[开发测试 MCP](08-开发测试MCP.md)，能力不足先补操作、等待和观测。每轮记录实际 DPR、窗口／画布视口、焦点及变化代次、场景代次与实际 backing store，成功／失败均留终态。环境变化不自动重试、不混入同条件统计；窗口／DPI、命中、单次提交、任务不变、取消／失效和无残留分别验收。

正式合成路径单独建立资源基线：每实例固定 20 轮打开／关闭，进程树采样峰值 ≤1280 MiB、释放态中位数增量 ≤64 MiB、后 15 轮释放态斜率 ≤2 MiB／轮。核心账本归零、Stage 销毁或进程退出不能代替这些门槛。当前失败先补 WebView 子进程角色与图像／Canvas 资源归因，再以预先固定的矩阵复验；不通过强制 GC、扩大门槛或反复运行改判。

生产包允许引入 Konva 正式绘制，但继续排除实验 HTML、开发工具、测试字体和私有资源；调整隔离断言对象，不全局关闭检查。验证窗口与历史报告保留。

M2 系统专项按原计划验收；达到阶段出口后推进 M3 固定快照参考图。M3 裁剪固定修订的保存时合成图，不依赖完整重绘，不截取带覆盖层的画布；素材导出和产品 MCP 继续各自后续出口。
