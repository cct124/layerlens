# 选区与任务

## 对象与职责

| 对象                | 作用                                           | 是否可变                     |
| ------------------- | ---------------------------------------------- | ---------------------------- |
| `UserSelection`     | 用户当前查看和选择的内容                       | 随用户操作变化               |
| `SelectionSnapshot` | 某次选区的完整内容、文档修订和解析后的目标范围 | 创建后不可变                 |
| `DesignTask`        | 固定一个快照，供 Agent 持续读取与导出          | 绑定范围不可变，可释放或失效 |
| `AgentHighlight`    | Agent 为解释结果而临时标出的图层               | 可更新，不写入用户选区       |

文档、图层 ID、边界和字符单位遵循[PSD 数据与素材](03-PSD数据与素材.md)。

## 选择类型

| `type`      | 必要信息                  | 范围解释                             |
| ----------- | ------------------------- | ------------------------------------ |
| `layer`     | `layerId`                 | 单个图层；组图层展开其有效可见后代   |
| `region`    | `bounds`                  | 文档像素坐标矩形，保留区域及相交候选 |
| `textRange` | `layerId`、`start`、`end` | 所属文字图层的原始文本区间；后续开放 |

`items` 可包含多个选择项。首版每次选择使用图层多选或单个矩形，不开放跨类型混合选择；接口类型保留扩展空间。

- 重复图层引用去重；同时选择组和其后代时规范化目标集合，避免重复导出。用户原始选择项可保留用于展示。
- 区域候选以有效可见图层与矩形有正面积交集为条件，仅接触边缘不算相交。优先使用可靠的视觉边界，否则使用几何边界并报告精度限制。
- 区域中相交的组不会自动扩展为整组；候选图层与实际矩形均保存在快照中，由 Agent 判断需要的素材。
- 隐藏图层可以在图层树中检查；首版任务默认排除不可见目标。选区只包含隐藏内容或没有有效目标时，不能创建实现任务。
- 文字片段范围不能拆分 UTF-16 代理对；界面应按完整字素选择，快照保留原始索引及选中文字。该能力完成验证前不对外声明支持。

## 实时摘要

每个 LayerLens 工具响应携带 `userSelection`。示意：

```json
{
  "sessionId": "session_01",
  "documentId": "doc_01",
  "documentRevision": 1,
  "revision": 18,
  "snapshotId": "selection_18",
  "itemCount": 1,
  "items": [
    {
      "type": "layer",
      "layerId": "layer_12",
      "name": "抽奖按钮",
      "bounds": { "x": 120, "y": 800, "width": 510, "height": 96 }
    }
  ],
  "truncated": false
}
```

- `sessionId` 标识核心实例生命周期，重启后改变；同一会话中的选择 `revision` 单调递增，切换文档、重载或清空也递增。
- `documentRevision` 属于文档版本，不能与选区 `revision` 混用。
- 没有选择时保留会话、文档和版本，使用 `snapshotId: null`、`itemCount: 0`、`items: []`、`truncated: false`。没有活动文档时，文档 ID 和修订也为 `null`。
- 摘要只携带有限数量的 ID、类型、名称、边界和少量文字；`itemCount` 是完整选择项数，截断时 `truncated: true`。完整快照不能从摘要反推或重建。
- 摘要与完整快照在同一次状态提交中生成。不能返回一个尚未建立、无法查找的快照 ID。
- 同一会话内可按 `revision` 丢弃较旧的返回；新会话需清除旧实例状态，不能将不同会话的版本号直接排序。

摘要大小上限和未绑定快照缓存预算在原型阶段确定，作为可测试配置维护。

## 快照与任务绑定

1. 选区变化后，核心对已发布文档修订创建不可变快照，保存完整选择项、规范化目标 ID、范围与能力提示。
2. Agent 从任意工具响应取得快照 ID，在用户下达实现指令后调用 `create_task`。
3. 核心校验快照仍可用且具有有效目标，以 `taskId` 固定其文档修订和范围。
4. 后续读取、预览、导出传入 `taskId`；当前选区变化只出现在响应摘要中。
5. 调整实现目标需创建新绑定。旧任务释放后可回收其引用；不提供就地替换任务范围的接口。

只查看快照也可通过显式 `snapshotId` 读取，但未绑定快照可能因缓存预算被回收。长流程必须创建任务。

`create_task` 要求客户端请求 ID，在同一核心会话内以相同请求 ID 和相同参数重试时返回同一任务；同一请求 ID 搭配不同参数返回冲突错误。重复请求不能静默创建多个任务。

`DesignTask` 记录任务 ID、快照 ID、名称、创建时间及 `active`／`released`／`invalidated` 状态。它不代表 Agent 执行状态；代码是否完成由用户或可选 Agent 集成确认。

## 生命周期

- 首版快照与任务只在当前应用会话内有效，不承诺跨重启恢复。持久化模块应单独设计源文件指纹与重新绑定机制。
- 应用仅展示一个活动文档，已绑定任务可继续持有旧文档修订。切换文档或重新加载不改变这些任务。
- 被任务引用的修订必须持有自包含的源数据或私有不可变副本；懒解码不能重新读取可能已被覆盖的源路径。
- 当前选区快照和绑定任务的快照不自动回收，其余未绑定快照受缓存预算控制。预算不足时明确拒绝新任务或提示释放，不悄悄失效正在使用的任务。
- `release_task` 幂等，阻止新的任务读取；已经固定引用的在途请求可正常结束，之后再回收无引用资源。
- 用户主动清理某文档全部资源时，先展示受影响任务，再将其失效并取消相关在途工作。退出应用也使会话内 ID 全部失效。
- 任务不可用分别返回快照过期、任务已释放、文档不可用等可识别错误，不退回当前文档或当前选区。

## 并发与采样

`data` 对应请求开始时固定的范围；`userSelection` 对应响应组装时一次原子读取的最新选区。响应必须携带各自的文档和版本，不能宣称两部分总是一致。

| 场景                     | 必须保持的行为                                               |
| ------------------------ | ------------------------------------------------------------ |
| Agent 处理 A，用户选择 B | 业务结果仍属于 A，摘要显示 B                                 |
| 计算期间切换文档         | 业务结果保留原文档修订，摘要可指向新文档                     |
| 用户清空选择             | 摘要返回空集合和更高版本，不回传上次选择                     |
| 两个响应逆序到达         | 客户端不以较旧选区版本覆盖较新状态                           |
| 旧快照已经回收           | 创建任务失败并要求重新获取选择，不绑定替代范围               |
| Agent 高亮旧任务中的图层 | 仅当其文档修订仍在当前画布展示时高亮，否则返回文档未激活错误 |

同一核心可能连接多个 Agent，用户选区是全局状态；任务各自绑定，高亮按连接分别记录并在断开时清理。一个连接清除高亮不影响其他连接的视觉标记。
