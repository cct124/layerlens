# 选区与任务

## 对象与职责

| 对象                | 作用                                           | 是否可变                         |
| ------------------- | ---------------------------------------------- | -------------------------------- |
| `UserSelection`     | 各文档分别保存的用户选择；对外摘要取活动文档   | 随用户操作变化                   |
| `SelectionSnapshot` | 某次选区的完整内容、文档修订和解析后的目标范围 | 创建后不可变                     |
| `DesignTask`        | 固定一个快照，供 Agent 持续读取与导出          | 绑定范围不可变，可释放或失效     |
| `ExportJob`         | 已接受的一次导出及其固定范围、进度和逐项结果   | 独立执行，完成、失败或取消后终止 |
| `AgentHighlight`    | Agent 为解释结果而临时标出的图层               | 可更新，不写入用户选区           |

文档、图层 ID、边界和字符单位遵循[PSD 数据与素材](03-PSD数据与素材.md)。

当前落地范围包括 M2-01 的 Rust 核心选区、不可变快照、任务绑定／释放及有界内容分页，以及 M2-02 桌面图层勾选、矩形草稿（新建／移动／边角调整）、固定任务、复制引用和内容查看，详见[当前核心实现与桌面适配](02-技术架构.md#当前核心选区与任务实现m2-01)。M1 查看器检查单选不建立任务授权；桌面变更回执与工作区选择通知分开，尚未实现 MCP 附带内容响应。本文的吸附、主动全部清理／失效、导出及 Agent 高亮仍是后续验收约定，新增桌面功能待 Windows 原生手测；示意 JSON 不是已发布的接口契约。

## 选择类型

| `type`      | 必要信息                  | 范围解释                             |
| ----------- | ------------------------- | ------------------------------------ |
| `layer`     | `layerId`                 | 单个图层；组图层展开其有效可见后代   |
| `region`    | `bounds`                  | 文档像素坐标矩形，保留区域及相交候选 |
| `textRange` | `layerId`、`start`、`end` | 所属文字图层的原始文本区间；后续开放 |

`items` 可包含多个选择项，但必须属于同一文档修订。首版每次选择使用图层多选或单个矩形，不开放跨类型混合选择；接口类型保留扩展空间。

- 重复图层引用去重；同时选择组和其后代时合并有效目标，但保留原始选择项及显式组授权。规范化后的同一目标只计一次。
- 区域候选以有效可见非组图层与矩形有正面积交集为条件，仅接触边缘不算相交。优先使用可靠的视觉边界，否则使用几何边界并报告精度限制。
- 每个候选保留完整原始 `bounds`，另附 `intersectionBounds` 及 `intersection: contained | partial`；后两者按实际用于命中的边界计算，`contained` 表示该边界完全落在区域内，不用交集覆盖原始边界。文字图层部分相交时仍读取全文，不根据矩形推测字符范围。
- 区域中相交的组及命中图层所需的父组仅作为结构引用，不成为有效目标，也不授权导出整组；候选图层与实际矩形均保存在快照中，由 Agent 判断需要的素材。
- 隐藏图层可以在图层树中检查；首版任务默认排除不可见目标。选区只包含隐藏内容或没有有效目标时，不能创建实现任务。
- 文字片段范围不能拆分 UTF-16 代理对；界面应按完整字素选择，快照保留原始索引及选中文字。该能力完成验证前不对外声明支持。

快照分别保存以下信息，不能以结构引用推导出额外的读取或导出授权：

| 信息                 | 含义                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| `items`              | 完整原始选择项；对外的同名字段仅为可截断摘要                                 |
| `targetLayerIds`     | 去重后的有效可见非组目标；显式选组展开其有效后代，区域选择只纳入实际命中目标 |
| `selectedGroupIds`   | 用户显式选择的组 ID；保留对该组及其有效可见子树的授权                        |
| `groupRefs`          | 解释层级和组样式所需的结构组引用；其存在不增加有效目标或组选区授权           |
| `dependencyLayerIds` | 已确定的额外图层像素依赖及对应关系；必须属于快照已选择的目标授权             |

蒙版数据、剪贴关系和父组结构属性可作为目标所需的描述信息，不能借此读取未选图层的额外像素。快照创建时固定已知依赖、范围及缺失能力；解析或导出后续发现依赖缺失或超出授权时明确失败。需要扩大授权时，由用户重新选择并建立快照，不能扩充原任务。

首版组导出只接受 `selectedGroupIds` 中的组及其显式授权子树内的有效可见组，并检查有效可见非组后代集合非空且全部属于 `targetLayerIds`、所需像素依赖均在授权范围内。区域中的结构组即使边界完全相交也不获得整组导出授权。同一批次请求组与其后代时按请求中的最外层完整组去重；需要单独导出后代时仅请求对应后代，不重复生成相同选择范围的输出。

## 区域草稿与提交

新建、移动、调整边角和吸附时只更新界面草稿，不更新对外选区、版本或任务。松开鼠标且范围发生变化后，核心确认有效矩形并原子提交新快照；范围未变不递增版本。拖动中按 Esc、开始中键平移、切换或关闭标签、重载文档时取消草稿，保留此前已提交选区，再执行相应状态变化。中键临时平移不提交或清空范围；松开后继续选区工具，旧草稿不恢复。过时的异步命中计算不得覆盖后续草稿或已提交选区。

显式点击移动工具是一次清空意图：取消草稿，通过核心清空当前文档的图层或区域选择；界面等待同一会话、文档修订及选择版本的清空回执和空摘要，再进入平移模式。不能只移除遮罩而保留隐藏授权。拒绝时保留原工具及有效选区；回执未确认时不提前显示清空成功。请求期间切换会话、文档、修订或产生更新选择／工具意图，旧回执不能切换新上下文的工具，也不清理另一文档。其他文档的选区和所有已固定任务保留；空范围切换无需额外提交。切回区域工具不恢复已经清空的范围。

区域工具空闲且画布获得焦点时，单按 Esc 是保留工具的清空意图，复用核心明确的清空操作；根据权威摘要移除范围和遮罩，不切换为移动工具。拖动或中键平移中按 Esc 只取消当前手势；重复按键事件不将取消升级为清空。忙碌、范围已空或上下文已变化时不追加请求；拒绝时保留有效范围。固定任务及其他文档选区保持不变。

成功的图层选择替换原区域选择并移除区域遮罩；新区域成功提交后替换原图层选择。无效或取消的选择操作保留此前已提交选择及其显示状态。“清空任务范围”、空闲 Esc 与点击移动工具均复用核心明确的清空操作，只有点击移动工具额外请求切换界面工具。工具状态的恢复以及普通标签切换不隐式清空范围。

## 实时选区与区域内容

每个 LayerLens 工具响应携带 `userSelection`。示意：

```json
{
  "sessionId": "session_01",
  "documentId": "doc_01",
  "documentRevision": 1,
  "revision": 18,
  "snapshotId": "selection_18",
  "itemCount": 1,
  "items": [
    {
      "type": "layer",
      "layerId": "layer_12",
      "name": "抽奖按钮",
      "bounds": { "x": 120, "y": 800, "width": 510, "height": 96 }
    }
  ],
  "truncated": false,
  "content": null
}
```

- `userSelection` 只表示活动标签的文档与选择；各文档独立保存选区，切换标签时恢复，不合并其他文档的选择。
- `sessionId` 标识核心实例生命周期，重启后改变；同一会话中的选择 `revision` 全局单调递增，仅在活动标签或其选区、文档修订变化时递增。后台文档重载或关闭不改变当前摘要。
- 切回保存的选区可复用原 `snapshotId`，但必须发布更高的 `revision`；两者无数值对应关系。
- `documentRevision` 属于文档版本，不能与选区 `revision` 混用。
- 没有选择时保留会话、文档和版本，使用 `snapshotId: null`、`itemCount: 0`、`items: []`、`truncated: false`、`content: null`。没有活动文档时，文档 ID 和修订也为 `null`。
- `items` 保持选择项摘要；顶层 `itemCount`、`truncated` 仅描述原始选择项及其是否未全部内联。单个区域的 `itemCount` 为 1，与区域命中的图层数量无关。原始摘要不提供逐项续读，也不承诺还原重复选择等冗余操作；完整有效目标通过 `get_design_context` 按快照续读，不能从摘要反推或重建完整快照。
- 创建选区时，摘要与完整快照在同一次状态提交中生成；恢复选区时，活动文档、选择版本与已有快照引用原子更新。不能返回一个尚未建立、已回收或无法查找的快照 ID。
- 同一会话内可按 `revision` 丢弃较旧的返回；新会话需清除旧实例状态，不能将不同会话的版本号直接排序。

区域选择的 `userSelection.content` 直接包含该快照命中图层、文字与关键样式；非区域选择和空选择为 `null`。内容在响应预算内时完整内联，超预算按显式游标续读：

| 字段                           | 含义                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------ |
| `layerCount`／`textLayerCount` | 完整投影中的唯一图层记录数（含结构组）、文字图层数；不因跨页重复计数，也不等于有效目标数         |
| `layers`                       | 当前批次的有效目标与必要组结构记录；分别标记 `role: target`／`structure`，结构组不能充当有效目标 |
| `truncated`／`nextCursor`      | 仍有未传输内容时为 `true` 和非空游标；全部传完为 `false` 和 `null`                               |
| `warnings`                     | 边界精度、属性缺失、不支持等限制；不将能力缺失当作待续页内容                                     |

- 图层信息保留 ID、父 ID、名称、类型、堆叠顺序、可见性、完整边界、适用的交集信息与关键样式；保留层级引用不会自动扩大命中范围。结构组随 `layers` 分页，不另行返回不受预算约束的完整组数组。
- 文字图层附完整原文、`styleRuns`、`paragraphRuns`、变换和能力状态，沿用[PSD 数据与素材](03-PSD数据与素材.md)的单位、来源和缺失语义。栅格化文字仍按图像处理。
- 长文本或样式超过单批预算时显式分页，分片携带 `textSlice: { start, end, totalLength }`；偏移始终对应原文 UTF-16 单位，分段样式保持原文偏移且随片段返回。分页拆分用于传输，不代表区域只选中了这些字符。
- 每个工具响应都携带所捕获选区版本的内容首批，即使此前已发送；不能只返回“已发送”标记。分页格式与 `get_design_context` 的默认区域内容输出一致，续读规则见[MCP 与 Agent 协作](05-MCP与Agent协作.md)。

选择项摘要、区域内容单批大小和未绑定快照缓存预算在原型阶段确定，作为可测试配置维护；全部规范化有效目标及其设计内容必须能够通过续页取得，不能静默丢弃。此保证不要求原样传输冗余原始选择项。

## 快照与任务绑定

1. 选区提交后，核心对单个已发布文档修订创建不可变快照，保存完整选择项、有效目标、显式组授权、结构引用、依赖、区域命中集合、范围与能力提示；文字和样式固定到该修订，不混合跨文档图层。
2. 用户以“这里”等当前选择下达新指令时，Agent 本次先调用 `get_selection`，以该响应的 `snapshotId` 调用 `create_task`，不沿用更早工具响应中的选区摘要。
3. 核心校验快照仍可用且具有有效目标，以 `taskId` 固定其文档修订和范围。
4. 后续读取、预览、导出传入 `taskId`；当前选区变化只出现在响应的 `userSelection` 中，不替换任务目标。
5. 调整实现目标需创建新绑定。旧任务释放后可回收其引用；不提供就地替换任务范围的接口。

普通指令的“当前选择”以本次 `get_selection` 的采样时点为准，不能推断用户发送消息时的历史选区。用户应等待绑定成功及范围反馈后再切换选择；需要下达指令后立即切走时，先在桌面固定任务并复制引用。任务引用包含 `sessionId` 和 `taskId`；已有任务同样可从桌面复制，Agent 核对会话后直接使用该引用。任务名称可以重复，不能仅凭名称或当前选择替代明确的任务引用。

只查看快照也可通过显式 `snapshotId` 读取，但未绑定快照可能因缓存预算被回收。长流程必须创建任务。

`create_task` 要求客户端请求 ID，在同一核心会话内以相同请求 ID 和相同参数重试时返回同一任务；同一请求 ID 搭配不同参数返回冲突错误。重复请求不能静默创建多个任务。

`DesignTask` 记录任务 ID、快照 ID、名称、创建时间及 `active`／`released`／`invalidated` 状态。它不代表 Agent 执行状态；代码是否完成由用户或可选 Agent 集成确认。

`ExportJob` 与 `DesignTask` 分开管理：接受导出时固定独立的范围与文档修订引用，保存进度及逐项结果，直到作业终态才释放执行引用。作业查询、取消和结果续读遵循[MCP 与 Agent 协作](05-MCP与Agent协作.md)，不能以任务是否释放代替导出作业状态。

## 生命周期

- 首版快照与任务只在当前应用会话内有效，不承诺跨重启恢复。持久化模块应单独设计源文件指纹与重新绑定机制。
- 应用可打开多个文档标签，同时展示一个活动文档。任务只绑定一个文档修订；切换、关闭标签或重新加载均不改变已绑定任务。
- 关闭标签释放该文档的查看引用；关闭活动标签时按[产品与交互](01-产品与交互.md)切换标签并递增选择版本。关闭非活动标签不改变当前摘要；关闭最后标签后发布空摘要，应用、MCP 与既有任务继续可用。
- 所有已发布修订在解析前即使用稳定的私有源数据，取得与发布规则见[技术架构](02-技术架构.md)。解析、懒解码及新建任务读取同一份不可变数据；源路径被覆盖或删除不会使活跃任务失效，也不能混入新的文件内容。
- 各打开文档的最新选区快照、绑定任务、在途请求及已接受导出作业持有的快照与文档修订不自动回收；其余资源受应用整体缓存预算控制。关闭标签后，任务、在途请求和导出作业引用仍受保护，无引用资源才可回收。预算不足时明确拒绝新增资源或提示释放，不悄悄失效正在使用的任务。
- `release_task` 幂等，阻止通过该任务发起新的读取或导出；已经固定引用的在途请求及已接受的导出作业可正常结束，之后再回收无引用资源。已发布文件和导出记录不随任务释放删除，其清理属于独立操作。
- 关闭标签不等于清理文档全部资源。用户主动清理某文档全部资源时，先展示受影响标签、任务和在途导出作业；确认后关闭其标签并释放查看与选区引用，再将任务失效并取消相关在途工作，等待执行引用释放后回收。已发布文件和导出记录仍按独立清理规则处理。退出应用也使会话内 ID 全部失效。
- 任务不可用分别返回快照过期、任务已释放、文档不可用等可识别错误，不退回当前文档或当前选区。

## 并发与采样

设计读取的 `data` 对应请求开始时固定的范围；导出及其结果查询始终对应作业被接受时固定的范围。响应组装时先原子捕获最新已提交选区并固定快照引用，再从该快照构建 `userSelection.content`；期间继续拖动或切换选区，不得拼出摘要 B、内容 C。响应必须携带各自的文档和版本，旧任务结果与当前区域内容可以属于不同文档或快照，不能互相替换。文档列表与当前选择查询的采样规则见[MCP 与 Agent 协作](05-MCP与Agent协作.md)。

| 场景                     | 必须保持的行为                                               |
| ------------------------ | ------------------------------------------------------------ |
| Agent 处理 A，用户选择 B | 业务结果仍属于 A，摘要显示 B                                 |
| 计算期间切换文档         | 业务结果保留原文档修订，摘要可指向新文档                     |
| 切回已保存选区的标签     | 恢复该文档选区，发布更高选择版本，可复用原快照 ID            |
| 关闭任务所用文档标签     | 任务继续使用已绑定修订；摘要属于新活动文档或为空             |
| 拖动或吸附区域选框       | 对外继续返回此前已提交选区；有效范围提交后才发布新版本       |
| 续读期间用户选择新区域   | 业务分页继续读取原快照，附带选区内容取最新已提交快照的首批   |
| 用户清空选择             | 摘要返回空集合和更高版本，不回传上次选择                     |
| 两个响应逆序到达         | 客户端不以较旧选区版本覆盖较新状态                           |
| 旧快照已经回收           | 创建任务失败并要求重新获取选择，不绑定替代范围               |
| Agent 高亮旧任务中的图层 | 仅当其文档修订仍在当前画布展示时高亮，否则返回文档未激活错误 |

同一核心可能连接多个 Agent；各文档保存用户选区，对外共享同一份活动文档摘要。任务各自绑定，高亮按连接和文档修订分别记录，仅绘制活动文档，并在连接断开时清理。一个连接清除高亮不影响其他连接的视觉标记。
