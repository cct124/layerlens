# LayerLens 设计文档

LayerLens 是基于 Rust + Tauri 的开源 PSD 解析与 AI 协作工具。用户在桌面端选择设计稿局部，编程 Agent 通过 MCP 获取结构化样式、参考图和素材，在目标项目中逐块实现 H5 页面。

本目录是首版设计基线，描述目标行为与验收要求，不代表功能已经实现。工程进度另由 `devlog/` 记录；当前仓库尚未建立应用骨架。

## 已定方向与待验证项

| 状态 | 内容 |
| --- | --- |
| 已定方向 | Rust + Tauri；本地 PSD 查看与局部选择；MCP 向外部 Agent 提供设计上下文 |
| 已定约束 | Rust 核心共享状态；实时选区与任务范围分离；缺失样式不使用猜测值代替 |
| 本稿约定 | `userSelection` 字段名、文档像素坐标、选择版本与快照、首版工具边界 |
| 首版范围 | 本地打开 PSD、单活动文档、图层与矩形选区、文字样式、预览、PNG 导出 |
| 候选选型 | Vue + TypeScript、`ag-psd-rs`、Rust MCP SDK `rmcp`；通过原型验证后锁定版本 |
| 后续扩展 | 文字片段选择、模块持久化、资源订阅、stdio 桥接、Codex 会话集成及更多 PSD 特性 |

“本稿约定”用于后续实现，可以在证据充分时调整；变更时同步对应文档、接口示例与验收项。候选库的功能、性能与维护状态须实测，不把讨论中的推荐直接视为兼容性保证。

## 阅读与维护

- 了解需求先读产品文档；实现前再读所属领域及其引用的规则。
- 同一规则只在所属文档维护，其他文档通过链接引用；术语与字段名称保持一致。
- `docs/` 保存当前设计和验收要求，`devlog/` 保存工程过程，仓库根目录 [AGENTS.md](../AGENTS.md) 规定协作流程。
- 不预设尚不存在的目录、命令或依赖已经可用；完成工程初始化后补充实际开发与验证入口。
