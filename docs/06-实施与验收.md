# 实施与验收

## 当前状态与实施原则

工程从 M0-00 最小 Tauri 脚手架开始，再由 M0-01 验证 PSD 解析与导出能力。当前工程状态及验证证据以[开发记录](../devlog/README.md)为准；初始化完成不代表整个 M0 完成，也不将候选解析器的说明直接当作首版验收结果。

先建立能独立测试核心、运行桌面和检查接口的最小工程，再验证真实设计数据，随后实现查看器、选择及 Agent 闭环。每个阶段以可复现结果作为出口；进度、失败尝试及下一步记录在 `devlog/`，不在多份设计文档中重复维护任务状态。

## 阶段与出口

| 阶段              | 主要工作                                                                                                   | 完成条件                                                                                            |
| ----------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| M0-00：工程初始化 | 建立 Rust workspace、独立核心 crate、Tauri 适配层、Vue + TypeScript 最小页、Rust DTO 类型生成及 Windows CI | 核心可独立测试；协议匹配与错误路径可验证；格式、类型、lint、测试、构建及桌面启动均有真实检查记录    |
| M0-01：解析原型   | 评估 Rust PSD 候选库，整理真实和合成样本，提取文字、边界、预览及简单位图                                   | 输出样本能力矩阵、准确性差异、耗时与内存基线；确定首版支持子集及解析器版本                          |
| M1：查看器        | 在已建立的工程中完成多 PSD 只读打开、顶部标签、左侧工具栏、中间画布、右侧图层树和只读属性区域              | 多份 PSD 可切换和关闭标签，视图按文档恢复；可定位图层和查看样式，加载失败保留已有文档，长操作可取消 |
| M2：选择与快照    | 实现各文档独立选区、图层多选、可调区域框、边缘吸附、区域内容关联、版本化返回、不可变快照与任务生命周期     | 选框移动与调整准确，吸附可控；切回标签恢复选区，任务不受切换、清空、关闭标签、重载和响应乱序干扰    |
| M3：预览与素材    | 裁剪参考图、按需解码、受支持 PNG 导出作业、清单及取消和错误处理                                            | 参考图与独立素材语义正确；成功文件可用，失败效果可识别，无目录越界和意外覆盖，取消结果可追溯        |
| M4：MCP 闭环      | 内嵌服务、工具 Schema、结构化响应、图像、分页、可恢复导出查询与 Agent 使用规则                             | 本地 Codex 可固定一个选区，读取样式和图像、使用导出素材，完成一个真实 H5 模块并对照验收             |
| M5：扩展验证      | 文字片段、模块持久化、资源通知、stdio 桥接、Codex 会话控制及更多格式                                       | 按独立需求和样本逐项验收；不作为首版发布前置条件                                                    |

M0 包含工程初始化和解析原型，只有两个子阶段均达到出口才算完成。MCP 联通原型可在 M1–M3 期间提前验证，避免到 M4 才发现传输或客户端兼容问题。不得因提前联通而跳过快照和导出验收。

M0 已形成的首版解析范围、版本与未验证项见[PSD 首版支持与解析器决策](07-PSD首版支持与解析器决策.md)。其出口是有证据的有限支持决策；完整文字排版、ICC、复杂素材与桌面响应继续在对应后续阶段验收，不能由成功打开或保存时合成图对照代替。

## 样本集

| 样本               | 验证内容                                                                         |
| ------------------ | -------------------------------------------------------------------------------- |
| 最小 RGB／8 位 PSD | 画布尺寸、分辨率、基础图层顺序、合成图与透明 PNG                                 |
| 真实 H5 活动稿     | 长页面、嵌套分组、常用文字和按钮、实际素材组合                                   |
| 多样式文字         | 字体、字号、颜色、字距、行距、对齐及同一图层内的样式分段                         |
| 特殊字符文字       | 中文、换行、emoji、组合字符，UTF-16 区间与原始文本一致                           |
| 变换与尺度         | 不同 DPI、文字缩放、旋转、非均匀变换、小数及负坐标                               |
| 层级与视觉依赖     | 重名图层、隐藏父组、空组、零面积或未知边界、透明边缘、蒙版、剪贴、阴影和父组效果 |
| 异常输入           | 无合成图、损坏文件、截断数据、超预算尺寸、首版不支持的模式和位深                 |
| 规模样本           | 不同文件大小、图层数、画布尺寸与可解码像素量，用于性能及缓存验证                 |

样本附预期图层信息和参考截图或已核对的属性值。项目外的真实设计稿不直接提交公共仓库；可公开样本记录来源和许可，私有样本通过可复现说明参与本地验证。

## 核心验收场景

| 场景                                   | 预期结果                                                                                                                   |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 打开新文件失败，或旧加载请求晚完成     | 已有标签保留；后台成功结果加入标签但不抢占后续选择，被取消结果不重新打开标签                                               |
| 同时打开多个 PSD 并切换标签            | 画布、图层树、属性与活动标签一致，各文档恢复缩放、平移、选区和图层树状态                                                   |
| 重复打开同一路径或打开同名文件         | 同一路径复用标签或进行中的加载，不同路径可同时打开；查询和选择使用文档 ID 区分                                             |
| 关闭后台、活动及最后一个标签           | 后台关闭不切换焦点，活动关闭按相邻顺序切换；全部关闭后无活动文档、摘要为空，已绑定任务仍可用                               |
| 使用左侧工具栏与右侧面板               | 左侧切换选择和区域选择工具，右侧图层树支持展开、搜索与多选，属性只读且可复制                                               |
| 使用任务、重载、目录配置与清理入口     | 可固定任务并复制当前会话引用，已有任务可再次复制；文件菜单／文档面板可重载，设置可改导出目录，清理前展示受影响范围         |
| 查看、选择、框选和导出                 | 不改变 PSD 源文件内容；无图层编辑或保存回写入口，导出生成独立文件                                                          |
| 在多个缩放比例下点击和框选             | 选择范围保持相同文档坐标；不重复应用 DPI 或视图缩放                                                                        |
| 拖动区域选框内部、四边和四角           | 移动保持尺寸，调整保持对边，最终矩形位于画布内；PSD 内容与画布尺寸不变                                                     |
| 区域选框显示、调整、提交及清空         | 框内原稿完整显示，框外内容仍可见且仅叠加黑色半透明遮罩；遮罩随选框更新，提交后保留、清空后移除                             |
| 区域带遮罩时读取预览或导出素材         | 输出只包含原稿内容，不包含遮罩、选框、控制点或 Agent 高亮；图层可见性和命中结果不受遮罩影响                                |
| 选框靠近画布边缘及图层边缘             | 吸附目标和参考线正确，不同缩放下触发距离一致；同距目标稳定，无边缘抖动                                                     |
| 关闭吸附、按住 Alt 或靠近隐藏图层      | 可自由精调，隐藏图层和其他标签不参与吸附；不将 Agent 高亮边界当作目标                                                      |
| 拖动过程中查询 MCP、取消或切换标签     | MCP 仍返回上次已提交选区；松开后只提交实际变化，取消和过时异步结果不产生新快照                                             |
| 选区模式中按住中键平移                 | 画布、选框内部及控制点均可起拖；光标显示抓手，文档范围和选择版本不变，松开后可继续框选；不触发默认自动滚屏                 |
| 左键拖动中追加中键、失焦或失去捕获     | 取消草稿并保留原有效范围；组合按键中先松中键也能结束平移，旧左键松开不提交已取消草稿；失焦后指针不再带动画布               |
| 点击移动工具结束选择                   | 取消草稿并请求核心清空当前文档，回执与同版本空摘要确认后才进入平移模式；遮罩和侧栏范围同步清空，固定任务及其他文档选区保留 |
| 移动工具清空失败、延迟或期间切换文档   | 失败保留原工具与范围且可重试；延迟时不伪装成功、不重复提交；旧回执不切换另一文档的工具，不清空新范围                       |
| 空范围切换工具或图层／区域选择切换     | 空范围进入移动模式不额外提交；清空后切回区域工具从空范围开始；有效图层选择替换区域并清遮罩，新区域取消或无效时保留原选择   |
| 选中组及其子图层、或选择重名图层       | ID 定位准确、目标去重，不重复导出                                                                                          |
| 框选只经过某组的局部                   | 保留区域与相交候选，不自动扩大到整组                                                                                       |
| 从区域请求父组导出，或显式选择组导出   | 区域中的结构组不能作为整组导出目标；显式组授权仍检查完整有效后代与依赖，同批组及子项按规范化输出去重                       |
| 图层具有零面积或未知边界               | 保留合法图层及原始信息，不伪造正面积；几何选区仍须有效，不以未知边界声称精确命中                                           |
| 区域完全包含或部分经过文字图层         | 返回文字原文、分段样式及相交标记，不按矩形猜测字符范围；隐藏图层按明确的可见性规则处理                                     |
| 区域包含大量图层或超长文字             | 内容在预算内时完整返回；超预算有总数、截断标记和续页游标，按快照续读可重建全部命中图层及原文样式                           |
| 区域内容续读期间切换选区或执行旧任务   | 当前区域内容与旧任务数据分别绑定各自快照，游标不能串用；原始选项数与区域图层数不混淆                                       |
| 读取文字和分段样式                     | 对应原稿属性；缺失字段、推导值和复杂变换均可识别                                                                           |
| 用户下达“这里”前后存在旧工具响应       | Agent 为本次指令刷新选区并绑定本次快照；桌面显示绑定文档与范围，用户看到成功反馈后再切换；不复用旧摘要                     |
| 用户复制固定任务引用后立即切换选区     | Agent 直接使用引用中的同会话任务，不重新绑定当前选择；旧会话引用明确失败                                                   |
| 以图层选择开始 Agent 流程              | 非区域选择的附带内容为空，Agent 调用设计上下文接口取得样式；不将空内联内容解释为图层无数据                                 |
| 绑定 A 后选择 B、清空或切换文档        | A 的业务结果不变，摘要准确反映当前选择与新版本                                                                             |
| 切回保留选区的标签，或关闭后重新打开   | 切回时选区摘要版本递增且原快照有效；重新打开生成新文档 ID，不替换旧任务引用                                                |
| 重载期间切换到另一个标签               | 重载成功仅更新原文档修订并清空其选区，不抢占当前标签；旧任务仍使用原修订                                                   |
| 查询非活动文档或列举已打开文档         | 不切换标签或选区；已关闭文档从列表移除，旧任务仍可按固定范围访问                                                           |
| 关闭或重载后通过任务查询文档信息       | 使用任务固定的文档宽高、DPI、色彩配置及能力报告，不读取新修订或要求标签仍打开                                              |
| 读取或复制源文件时被原地写入或原子替换 | 仅在能取得一致源数据时发布修订，否则报告源变化并拒绝混合发布；失败不覆盖已有文档                                           |
| 源文件被覆盖或删除后读取旧任务         | 尚未解码的图层仍可从固定旧修订解码与导出，像素保持一致；源路径变化本身不使任务不可用                                       |
| 响应乱序、重复创建任务、释放任务       | 旧选择不覆盖新状态；创建幂等；释放不再接受新的读取                                                                         |
| 未绑定快照被回收或应用重启             | 明确返回生命周期错误，不自动绑定其他范围                                                                                   |
| Agent 高亮及多连接操作                 | 不改变用户选择；各连接高亮互不覆盖，断连后清理                                                                             |
| 导出不支持效果或部分图层失败           | 默认拒绝不受支持的导出，逐项报告，成功清单只引用完整文件                                                                   |
| 导出含小数、负坐标或阴影的素材         | 实际栅格范围向外取整，尺寸与 PNG 一致，保留完整效果及可还原的文档原点和选区偏移                                            |
| 图层名包含路径字符，或导出位置已存在   | 输出仍在配置目录内，名称安全且唯一，不覆盖已有结果                                                                         |
| Agent 读取素材期间更改导出根目录       | 清单提供该作业固定的绝对根目录及相对路径，拼接后可定位原文件；新配置不改写既有导出位置                                     |
| 大批量导出或单次响应预算不足           | 副作用前完成准入；状态结果与当前区域首批符合总预算，终态清单可稳定分页重建全部逐项结果                                     |
| 素材全部写出，但清单文件发布失败       | 作业为部分失败，清单发布状态为失败且路径为空；素材成功计数不变，仍可按作业查询完整逐项结果                                 |
| 导出响应丢失、重复请求或 MCP 断连      | 原请求引用可查回同一作业及结果，不重复写入；已接受作业断连后继续，终态结果在当前会话内可恢复                               |
| 预览或导出期间取消、释放任务           | 释放阻止新任务读取但不取消已接受导出；用户取消不发布半成品或晚到成功，保留已发布完整项及其余项状态                         |
| 取消与导出完成同时发生                 | 核心确定先后：取消先提交则不再发布新素材，完成先提交则保持原终态；取消结果查询不取消导出本身                               |
| MCP 分页、图像和错误响应               | Schema 有效、范围一致、图像可被客户端读取、错误可定位和恢复                                                                |
| 本地 MCP 凭据、监听与连接配置          | 验证有效及无效凭据、适用 Host／Origin 校验和回环监听；端口冲突可恢复，界面展示实际可用地址                                 |
| H5 模块实现                            | 在明确 CSS 比例和字体条件下核对字号、颜色、布局及素材；记录浏览器、视口、字体来源或版本、基准图及差异，范围始终受用户控制  |

范围、导出和传输行为分别以[选区与任务](04-选区与任务.md)、[PSD 数据与素材](03-PSD数据与素材.md)及[MCP 与 Agent 协作](05-MCP与Agent协作.md)为准；验收记录须覆盖上述失败和恢复路径。

### 主动清理验收

- 核心自动回归：预检只读且不固定源数据，跨实例计划拒绝；选区、任务、修订或已知加载／预览变化使旧确认无副作用地失败。确认并发与同计划重试只清理一次，选择版本耗尽不能留下半失效。
- 同文档所有保留修订及活跃任务失效，旧图层／内容读取与待提交选择被拒绝，已释放任务不改状态；其他文档、当前非目标选区、同路径重开及其重载不受影响。任务终态／幂等记录继续占额度。
- 受控检查点验证排队／执行中的解析和预览取消、晚到成功不发布、未规范化别名不重开；在途与外部引用释放前继续计费，释放后核对源／范围／PNG 账本。已返回图像不删除，不能以账本代替进程 RSS 测量。
- 桌面接入后再验收：当前标签和已关闭文档任务入口均列明影响；取消确认无变化，影响改变提示重新确认，重复确认安全。任务显示“已失效”，旧内容／引用与迟到响应不复活；关闭标签和普通释放不弹出或触发全部清理。此项仍待实现与 Windows 原生手测。

### 边缘吸附验收

- 区域工具默认勾选“边缘吸附”。在 25%、100%、200% 缩放下，分别新建、移动和调整八个边角，确认按屏幕距离进入／脱离，参考线与目标名称对应；新建起点不跳动，移动保持尺寸，调整固定原对边，反向跨越也有效。阈值以[产品规则](01-产品与交互.md#区域选择与吸附)为准，原生手感待验收，不将自动测试当实测结论。
- 同距画布优先，重叠或相邻图层目标稳定；已锁定目标在脱离前不被旁边更近的线抢走。靠边图层吸附后继续往画布外拖动，能够脱离并到达画布边缘，不被裁剪位置永久锁住。
- 关闭开关可自由精调；拖动时指针不动，按下 Alt 立即取消吸附和参考线，松开重新判断。按住 Alt 松开鼠标提交自由矩形；不足最小拖动、零面积或未变更不提交。切换开关不改变当前有效范围或固定任务，跨标签保留开关，本次运行结束后恢复默认开启。
- 隐藏图层及隐藏父组后代、组、零面积和画布外图层不参与；搜索／折叠不减少目标，图层检查焦点和已固定任务也不成为额外目标。提示“几何边缘”，不能把有阴影等效果的外观边缘当作已验证目标。
- 图层分页中／失败时仅画布吸附，完整读取后下一次手势启用图层目标，进行中的选框不跳动。取消、Esc、中键、失焦、丢失捕获、缩放、调整面板／视口、切换或重载后，参考线消失，迟到松开不提交。
- 松开之前右侧有效范围与任务不变；松开后提交吸附矩形，核心拒绝时恢复旧范围并提示。分别核对不同文档／修订与固定任务，不能因吸附改变先前固定目标。

### Esc 快捷键验收

- 区域工具、画布获得焦点、没有拖动时按 Esc：请求核心清空，权威摘要确认后移除范围和遮罩，保持区域工具；失败保留原范围并可重试，忙碌或空范围不追加请求。
- 拖动选框或中键平移时按住 Esc：首次只取消手势，长按重复事件不清空；松开后再次单按才清空。任务名称等画布外输入和输入法组合状态不受影响，其他文档和固定任务保持不变。

### 自定义标题栏验收

- 重新启动 `npm run dev` 以加载窗口配置与权限（仅 WebView 热更新不足）；确认只有一行标题／菜单，不再有系统标题栏，右上角三个窗口按钮完整可达。重启会结束当前会话及任务，不把旧进程结果当作新配置验收。
- 拖动顶部空白、品牌和只读状态区移动窗口；双击这些区域最大化／还原，按钮图标与名称同步。点击文件／视图／窗口标题、菜单项或窗口按钮不拖动窗口，不产生两次最大化切换。
- 最小化后从任务栏恢复；分别用按钮、双击及系统快捷键改变最大化状态，核对恢复后的图标、菜单键盘焦点和画布布局。标题栏按钮在工作区未连接或无文档时仍可操作，命令失败显示原因且可重试。

- 浏览器预览不显示窗口控制且不调用 Tauri；组件卸载和订阅晚到不遗留监听或更新已销毁视图。自动测试覆盖调用与生命周期边界，不能替代上述原生验收。

### 紧凑工作区与面板验收

- 顶部为“文件／视图／窗口”菜单，下方保留工具选项；文件菜单打开／重载／关闭文档走现有核心入口，关闭不释放固定任务。无文档、忙碌或文件对话框打开时，相关菜单项按准入条件禁用。
- 菜单可鼠标打开、悬停切换、点击外部收起，支持 Alt+F／V／W、方向键、Home／End、Enter／空格和 Tab。菜单内 Ctrl+O／0／1 可执行已有命令；菜单内按 Esc 只关闭菜单并恢复标题焦点，不清空当前选区或切换工具。窗口失焦和组件卸载不遗留打开菜单或监听器。

- 在 Windows 开发版默认窗口、最小 900 × 600 窗口和最大化状态检查布局；系统 100%／150%／200% 缩放分别验证。顶部保持紧凑，右侧标签始终可达，画布不被侧栏挤出，工具提示和错误信息可读取；未实测的 DPI 不写为已验证。
- “属性／文档”和“图层／任务”独立切换，Tab 仅进入活动标签，方向键及 Home／End 可切换。长属性、长任务内容、图层列表各自滚动，不带走另一组标签；回到图层恢复搜索、展开和滚动，任务名称草稿不丢失。
- 右侧左边缘及上下交界使用透明拖动热区，不出现明显分隔线或悬停／拖动高亮，悬停只切换对应调整光标。拖动实时改变宽度／高度，不误触外层窗口边缘缩放；鼠标在画布或面板正文中仍保持原操作。键盘聚焦热区有可辨认焦点，方向键、Home／End 调整受约束且不触发工具快捷键。
- 尺寸遵循[产品与交互](01-产品与交互.md#界面布局)的默认值和最小／最大约束。宽度与比例在松开后记忆，重启仅恢复尺寸、不恢复会话任务；缩小再放大窗口可回到原偏好。双击仅重置对应方向，窗口菜单重置两轴；无文档时也可重置。存储损坏／拒绝时明确提示，仍可继续调整。
- 拖动中 Esc、失焦、指针取消或窗口尺寸变化撤销本次调整，松开或继续移动不能复活已取消手势，再次拖动仍正常；卸载不残留全局光标或禁用内容。取消／重置均不清空已提交选区、切换工具、提交任务或丢失搜索与任务名称草稿。
- 面板调整后图层虚拟列表填满可见高度，不重建任务输入。手动缩放下画布比例与平移不变，“适应窗口”下按新视口适配；有效选区继续按原稿坐标显示，未提交的画布拖动因视口变化取消。上述行为在最小窗口、最大化和各 DPI 下分别手测。
- 点击图层名称显示上方属性，勾选只改变核心任务范围；可见性图标只读。窗口增高后图层填满可见区域，4096 条列表仍只渲染视口附近行；隐藏面板和分页期间不覆盖保存的滚动位置。
- V／M 与工具按钮行为一致；V 清空失败时即使停留图层面板也能看到错误，回执未确认前不切换。输入任务名称或图层搜索时不触发工具快捷键；Ctrl+O 调用现有文件选择，Ctrl+0／1 仅改变画布视图。
- “查看任务”始终可达，关闭最后一个文档后仍能读取已固定任务；面板切换不创建新任务或改写授权。长路径通知可展开完整原因，关闭通知不影响文档与任务。
- 不新增未实现的保存、编辑、滤镜、导出或 AI 连接菜单；深色主题不改变原稿图像色彩。此批只验证工作区重构，不替代 M2 吸附、完整生命周期或 release 安装验收。

## 性能与诊断

先建立样本和环境基线，再设定性能预算。不得在尚未实测时宣称“大文件秒开”或比其他语言方案更快。

每次性能实验至少记录操作系统、CPU、内存、构建模式、依赖版本、样本指纹、文件大小、图层数、画布尺寸及冷／热缓存条件，并区分：

- 打开文件到元数据可用、到首张预览可见的耗时。
- 选择、吸附及属性展示的响应耗时，后台工作期间的界面可操作性；拖动查询、快照提交和内容序列化分别记录。
- 解析、解码、裁剪和导出的阶段耗时及峰值内存。
- 解析实验分别记录稳定源读取、容器预检、候选解析、规范化、源指纹及源缓冲释放；PNG 输出分别记录解码、编码和写盘。写盘未显式同步到物理设备时须说明系统缓存条件。
- 首次进程运行与重复运行分开统计，未清空系统文件缓存时不能称为冷读；连续打开、解码、释放记录存活工作集和私有内存，进程峰值与对象释放后的占用分开解释。
- 缓存命中、回收效果、多文档同时打开、连续切换及关闭标签后的占用，区分任务仍持有的修订与可回收缓存。
- MCP 响应延迟、JSON／图像大小、分页和取消行为。

M0-01 依据样本结果提出资源上限、并发数与响应预算，后续阶段验证而非凭经验写死。用户可感知的卡顿须单独验证，不能仅用后台吞吐量替代。
