# 产品与交互

## 目标与场景

H5 活动开发中，仅向 AI 提供截图很难准确恢复字体、字号、颜色和素材边界。整页生成也难以控制实现范围和修改节奏。

LayerLens 让用户从 PSD 中选出“抽奖区”“排行榜”“奖励弹窗”等局部，将原始设计数据与视觉参考一起交给已有编程 Agent。用户决定处理范围与顺序，Agent 在目标项目中沿用现有组件和页面适配方式。

LayerLens 负责忠实提取和解释结构化设计数据，提供来源、单位、变换、能力限制及视觉参考；不生成目标项目的 CSS，也不推断布局、响应式策略或字体替代。这些实现决策由 Agent 结合目标项目作出，是产品的持续职责边界，不仅适用于 M0 实验阶段。数据规范化及有依据的设计空间单位换算不等于生成 CSS，具体语义见[PSD 数据与素材](03-PSD数据与素材.md)。

核心流程：打开 PSD → 选择局部 → 下达实现指令 → Agent 绑定快照并获取数据 → 编写代码 → 对照检查 → 处理下一个模块。

## 首版范围

| 能力       | 首版行为                                                         |
| ---------- | ---------------------------------------------------------------- |
| 打开设计稿 | 本地只读打开多个 PSD，通过顶部文档标签切换当前文档               |
| 查看设计稿 | 合成预览、缩放和平移；图层树、图层属性与边界叠加                 |
| 选择范围   | 图层、图层组、多选、可调整且支持边缘吸附的区域选框；支持清空选择 |
| 读取样式   | 文字内容、分段样式、字体、字号、颜色、位置与变换，保留缺失信息   |
| 获取参考   | 在原稿合成图上裁出局部参考图，说明裁剪范围与比例                 |
| 导出素材   | 导出能力范围内的独立 PNG 及素材清单，明确效果限制                |
| Agent 协作 | 本地 MCP、返回附带选区与区域内容、不可变任务快照、Agent 图层高亮 |

LayerLens 只读 PSD，不提供设计内容修改或保存回写功能；素材导出生成独立文件。首版不包含完整 Photoshop 渲染、内置 H5 代码编辑器或自动整页生成。PSD 颜色模式、位深及复杂效果的兼容性由解析器能力与样本验证确定，见[PSD 数据与素材](03-PSD数据与素材.md)；PSB 支持另行验证。

文字片段选择在数据模型中预留，待命中测试和字符范围验证通过后开放。持久模块、跨重启恢复任务和 Codex 内嵌会话属于后续能力。

## 界面布局

参考 Photoshop 的布局和操作习惯，采用左侧工具栏、中间画布、右侧面板，降低已有 Photoshop 使用经验的用户的学习成本。

| 区域           | 内容与行为                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| 顶部操作栏     | 打开文件、缩放、适应画布、Agent 连接状态；设置中配置连接与素材导出目录                                |
| 文档标签栏     | 位于画布上方，每个已打开 PSD 对应一个标签；显示文件名、活动状态与关闭入口，点击切换，标签菜单支持重载 |
| 左侧工具栏     | 类似 Photoshop 的竖向工具栏，包含选择工具、区域选择工具；区域选框可移动、调整和吸附，工具显示名称提示 |
| 中间画布       | PSD 参考图；平移、缩放、图层点击与区域框选；分别显示用户选区和 Agent 高亮                             |
| 右侧面板区     | 以类似 Photoshop 的图层树为主，展示层级、类型及可见状态；支持搜索、展开、选择和多选，配套只读属性区域 |
| 任务与导出面板 | 绑定结果、所属文档与固定范围、参考图、导出进度和结果；支持固定任务、复制引用、释放任务和资源清理      |

右侧属性区域展示选中内容的文字、样式、坐标、尺寸、素材及能力提示，支持查看和复制，不提供编辑输入。缺失字体、无法读取的样式及未支持效果明确标记。协议字段、内部 ID 等放在连接设置或诊断信息中。

资源清理入口先列出受影响标签、任务和导出，用户确认后关闭相应标签、使任务失效并取消相关工作；普通任务释放允许已经开始的导出继续完成。已导出的文件不随任务释放删除，清理导出文件是独立操作。具体规则见[选区与任务](04-选区与任务.md)。

图层树不提供重命名、拖动排序、增删图层或修改可见状态的操作。选择和框选只确定查看与实现范围，不移动、变形或裁剪 PSD 内容。

## 文档标签与切换

- 可同时打开多个 PSD，每次激活一个标签；画布、右侧图层树和属性区域随活动标签联动。
- 每个文档独立保留缩放、平移位置、选区及图层树展开和滚动状态，切回时恢复；切换本身不重新解析文件。
- 重复打开同一路径的已打开文件时激活已有标签。同名但不同路径的文件使用不同标签，可通过路径提示区分。
- 成功打开的文件加入标签栏；加载失败保留已有文档。后台加载完成时遵循最新打开或切换意图，不抢占用户后来选中的标签。
- 从标签菜单显式重载成功后更新该文档并清空其选区，失败则保留原内容；重载不抢占其他活动标签，也不改变既有任务的固定范围与数据。
- 关闭活动标签后激活其右侧相邻标签，没有右侧标签时激活左侧；关闭后台标签不改变当前标签。关闭最后一个标签显示空工作区。
- PSD 始终只读，关闭标签无需保存设计稿。关闭只移除该文档的查看入口，已绑定任务保留原快照并可继续读取或导出；内存回收规则见[选区与任务](04-选区与任务.md)。

## 选择操作

- 左侧区域选择工具用于新建和调整矩形；点击移动工具表示结束本次范围选择：先取消草稿，再通过核心清空当前文档的已提交范围（图层选择或区域选择）。收到对应清空回执及空选区摘要后进入平移模式，并移除区域遮罩和控制点；清空失败保留原工具和有效范围并提示原因，未确认时不提前显示成功。选区操作忙碌时移动工具暂不可用，避免重复提交。空范围可直接切换。
- 选区模式下按住鼠标中键拖动画布可临时平移，松开后继续框选；光标在平移时显示抓手。中键在画布、选框内部和控制点上都有效，屏蔽默认中键自动滚屏。若正在左键新建／移动／调整选区，追加中键先取消草稿并恢复已提交范围，再平移；中键松开、指针取消、捕获丢失或窗口失焦结束临时平移，不恢复旧草稿。
- 中键平移、滚轮缩放和方向键移动只改变视图，不改变已提交选区的文档坐标或版本。显式点击移动工具、“清空任务范围”或区域工具空闲时按 Esc 可请求清空当前范围；其他文档选区和固定任务不受影响。通过移动工具清空后切回区域工具从空范围开始；切换标签仍恢复该文档自身的范围，不因工具处于移动模式而自动清空。
- 画布获得焦点时，区域工具空闲状态按 Esc 清空当前范围，保持区域工具，可直接重新框选。拖动选框或中键平移过程中按 Esc 只取消当前手势并保留已提交范围；松开 Esc 后再次单按才会清空。按住 Esc 的重复事件、输入法组合状态不触发清空；任务名称等画布外输入不受影响。操作忙碌时不追加清空，范围已空时不发请求，失败保留范围并提示。
- 图层树支持单选、多选和图层组选择。选中组代表其有效可见后代；隐藏成员可检查，但不默认成为导出目标。
- 图层树或画布中的有效图层选择替换已有区域并移除遮罩，作为一次选择变更提交；新区域仅在有效提交时替换原图层选择，取消或无效拖动保留此前选择。
- 画布点击优先使用可用的像素命中信息，否则使用边界候选。重叠或边界命中不明确时允许切换候选，不能把矩形命中宣称为精确像素命中。
- 框选保存真实矩形，并显示相交图层候选；不会自动把整个候选组都变成任务目标。规则见[选区与任务](04-选区与任务.md)。
- 用户高亮与 Agent 高亮使用不同标识；Agent 高亮不修改选区，也不自动切换活动文档。
- 清空选择是一次明确的状态变更；没有选择时，不将整张 PSD 自动当作实现范围。

## 区域选择与吸附

- 交互参考 Photoshop 裁切工具：拖出矩形，拖动内部移动选框，拖动四边或四角调整大小。选框始终位于画布内，只圈定查看与实现范围，不改变画布尺寸或 PSD 内容。
- 选区内按原稿完整显示，不叠加遮罩或调暗；选区外保留原稿可见内容，仅叠加黑色半透明遮罩，不隐藏其他区域。遮罩随选框移动和调整同步更新，提交后保留，清空区域选择后移除，使所选范围与周边内容的位置关系清晰可辨。
- 选框边缘默认吸附当前画布边缘及有效可见图层的边缘。优先使用可靠的视觉边界，否则使用几何边界并说明精度；不吸附隐藏图层、其他文档或 Agent 高亮框。
- 移动选框时保持尺寸，调整边角时保持未拖动的对边。显示吸附参考线与目标；提供吸附开关，并可按住 Alt 临时关闭吸附。
- 吸附距离按屏幕 CSS 像素计算，再随画布缩放换算到文档坐标。每个方向优先吸附最近边缘，同距时优先画布；进入与脱离吸附使用不同阈值以避免抖动，具体数值通过交互样本确定。
- 拖动过程中只更新选框预览；松开后范围有效且发生变化时提交一次。Esc 取消本次拖动并恢复上次选择；切换标签、关闭或重载文档也取消未提交拖动。中键平移只取消草稿；点击移动工具则取消草稿后按上述规则清空已提交范围。
- 已提交区域关联范围内的图层与文字内容，保留完全包含或部分相交的区别；部分经过文字图层时不猜测字符截取。内容返回及快照规则见[选区与任务](04-选区与任务.md)。

## 与 Agent 配合

1. 用户打开 PSD 并选择内容，在 Agent 中发出“实现这里”等明确指令。
2. Agent 为本次指令主动刷新当前选区，再绑定此次取得的快照；不沿用此前工具响应中的选择。普通“这里”以本次刷新时的已提交选区为准。
3. 桌面端显示绑定成功、所属文档与固定范围。用户看到该反馈后即可继续查看其他位置；原任务继续使用已绑定范围。
4. Agent 读取该任务的文字样式、参考图与素材清单，再修改目标 H5 项目。区域选择在工具响应中附带内容首批；图层选择需主动读取设计上下文，内容较多时均按同一快照续读。
5. 用户明确要求调整目标时，Agent 建立新的任务绑定；完成后释放不再使用的任务。

首版提供“固定任务并复制引用”：需要发出指令后立即切换选区时，用户先固定当前范围，将复制的任务引用连同要求粘贴给 Agent；已有任务也可复制引用。界面展示任务名称、所属文档和范围，Agent 使用引用直接读取该任务。普通流程不要求用户先手动创建任务；引用仅在当前应用会话内有效，具体绑定规则见[选区与任务](04-选区与任务.md)。

任务用于保存设计范围，通用 MCP 模式下不推断 Agent 是否已完成代码实现。导出显示进行中、完成、部分完成、失败或已取消；连接中断后可查询原导出的进度和结果，不因重试重复导出。用户可在桌面端取消导出，已完成文件仍在结果中列出，其余项明确标记。

工具调用返回选区只提供下一次响应时的感知能力。Agent 没有调用 LayerLens 时不会立即收到新的模型输入；自动发起执行不属于首版承诺。

## 异常与反馈

| 情况                           | 用户可见行为                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| 格式不支持、文件损坏或解析失败 | 显示原因及可用操作，保留此前可用的活动文档                                             |
| 无合成预览                     | 明确显示预览不可用；仍可查看已解析的图层数据                                           |
| 样式、字体或效果缺失           | 在相关属性或导出结果处标记，允许用户据此改用素材或更换设计稿                           |
| 快照过期或任务失效             | 告知需重新选择或绑定，禁止悄悄使用当前选区替代                                         |
| 导出部分失败                   | 展示成功项和失败项，失败项不能伪装成完整导出                                           |
| MCP 断开                       | 保留桌面查看与选择能力，显示连接状态及连接配置入口；已接受的导出继续，可重连后查询结果 |

解析、预览与导出显示处理状态并允许取消。是否满足交互性能要求以[实施与验收](06-实施与验收.md)中的实测记录为准。
